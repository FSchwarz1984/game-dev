# 《ツヅラ —遠囃子—》 设计文档 v0.1

> 一只背着家走路的貂妖，在“距离”坏掉的世界里，用脚把远处走回近处。

本文档对应仓库中的第一个可玩版本（序章 + 九十九折峠的第一天）。它同时是设计圣经的第一稿：哪些已经实现、哪些只是方向，逐条标明。

## 0. 结论先行

| 维度 | 决定 |
|---|---|
| 类型 | 像素风 · 开放世界 · 运输/开拓 × 据点经营 |
| 主角 | 葛笼（ツヅラ），九十九折峠的貂妖，自封“峠之主” |
| 灾变 | **遠化**（人类称谓）／**遠囃子**（妖怪称谓）：被无源的祭囃子“邀请”的东西变得永远走不到 |
| 核心动词 | **背**（背负子上的货堆）＋**重**（取／予：重量的守恒借贷）＋**走**（每一步都在地上磨出路，并把被漂白的地方走回“近”） |

| 渲染 | 2.5D 延迟光照像素管线（详见 §6），全部美术与声音由代码生成 |

## 1. 对旧 demo《流れぬ雛》的结构诊断：为什么它走不远

**1.1 主体的欲望结构是闭合的。** 形代（流し雛）的目的是“被流走”。主角达成目标的时刻就是主体被取消的时刻：叙事终点 = 角色终点。这样的结构可以做一部精致的短篇，但无法向“栖居、经营、共同体”展开——因为主角不想留下来。

**1.2 核心动词是解谜动词，不是世界关系动词。** 「移」（重/熱/光/音 × 取/予）组合空间很漂亮，但它天然生成的是“关卡谜题”：每个机关等待一个正确的性质组合。它不生成路线、负重、往返、积累，也就不生成经营与长线。

**1.3 拓扑封闭。** 一个盆地、一道堰、一个目标（开堰）。探索被唯一目标吸收，好奇心没有独立的回报回路。

**1.4 IP 辨识度不足。** 16×28 的红衣纸人是民俗现成品，轮廓与大量和风作品重叠，缺少“轮廓 + 性格矛盾 + 内在秘密”三件套。

**1.5 技术面。** 3D→像素的思路是对的，但低多边形道具读起来像程序员美术；渲染管线（阴影、水、雾、描边）是旧作真正的资产。

**扬弃（保存了什么）：**
- 「移」的**守恒结构**保留，但只保留一个性质——**重**——并把它从谜题物理改写为运输物理（见 §4.2）。
- “主角自身也是系统的一部分”保留，发展为**性质极值即化身**（石化／叶化）。
- 伪 3D 像素渲染路线保留，并整体升级为延迟光照的 2.5D 管线。

**抛弃：** 纸人主角、堰的目标结构、热/光/音三种性质（留作后续“化身”的扩展槽，而不是一开始就全部端上桌）、付丧神作为敌人的设定（付丧神在新作里是被照料出来的伙伴）。

## 2. 世界：遠化 / 遠囃子

**现象。** 盂兰盆送魂的那一夜（八月十六日），全国各地同时听见无源的祭囃子。凡是被这音乐“邀请”的东西都**遠化**：它们仍然看得见，却褪成远山的颜色；你朝它走，它就以你的步速后退。城市、铁路、桥、家人，都还“在那里”。

**两套命名，一个缝隙。**
- 人类：「遠化現象」；收音机碎片里反复出现军方否认与「隔」计划有关——一种让敌国“无法抵达”的防御工程？
- 妖怪：「遠囃子」——常世（とこよ）的祭典在靠近；夜空里有一列灯笼正往天上走（百鬼夜行的意象）。
- 两套解释都不完整，而且互相指控：人类会认为这是大规模神隠し（妖怪所为）；妖怪会认为这是人类工程撕开了与常世之间的“隔”。这是第一章“被排斥”的结构来源，不需要道德化。

**终极之谜（只在系统里成立，永远不在台词里讲出来）。** “近”究竟是什么？本作的回答方向是：近不是空间的属性，而是被照料、被使用、被走过的关系的沉积。现代性废除了距离，却没有生产出近（海德格尔《物》）；遠化不是攻击，而是**显影**——它让早已遥远的东西显出远的颜色。玩法上对应的就是：**走过的路会变近；被背着走了很远的物会醒来。**

**与《死亡搁浅》的关系：只学方法，不借概念。** DS 的灾变是生死界限崩溃，答案是“连接”（网络）。本作的灾变是“邻近性”崩溃，答案是“栖居”（磨损出来的路、被照料的物、被数着的供品）。学到的四条方法：
1. 把形而上的东西物质化（距离 → 一种可以被“走回来”的地表属性）；
2. 灾变的现象学有自洽的内在规则（看得见、够不到、以你的步速后退、远方的颜色、远方的声音）；
3. 核心动词是对灾变的结构性回应（走 = 让近重新发生）；
4. 主角的存在方式与灾变有特殊关系（她早在遠化之前就已经“远”了，见 §3）。

## 3. 主角：葛笼（ツヅラ）

**种族：貂（テン）。** 民俗里「狐七化け、狸八化け、貂九化け」——貂是最会变化的；「貂の道切り」——貂横穿道路是凶兆；而「道切り」同时是村口挂绳辟邪的仪式。她是“横穿道路的妖怪”，在道路失效的世界里成为开路的人。（貂在主流作品里几乎是空白生态位，这是原创性的护城河。）

**名字一词四义：** 九十九折（つづらおり，盘山路的连续弯）/ 葛籠（藤编的箱笼）/ 葛（藤蔓）/ 九十九（付丧神的“九十九年”）。她是“盘山路之主”，背着“箱笼”，用“藤”修祠，而她永远只数到“九十九”。

**轮廓（剪影优先）：** 金发、黑褐色发梢（貂的冬毛），圆耳，琥珀色眼睛，一颗虎牙；藏蓝絣的短打和服、红色襷、腰间一枚铜铃；深色股引 + 脚绊 + 草鞋（旅人装，腿是貂的深色）。**背负子**——竖在背后的木梯架——是她最可识别的轮廓；背上的货堆越高，剪影越夸张，也越可爱、越危险。

**性格矛盾：** 浮夸的名乗り（“吾乃九十九折峠之主，葛笼是也！”）× 一个三年没有收到新供品、被铁路隧道绕过的路边小神。幽默来自人物逻辑（她会把偷吃供品说成“是风”“是老鼠”），悲伤只做减法（“上一个走这条路的人，是三年前的夏天。”）。

**口癖与秘密：** 强迫性计数，永远停在九十九。为什么不数到一百？民间的百物語：讲完第一百个故事，真的会来——“数到一百的东西，会变成别的东西。”这是可以支撑系列的内在谜题。（v0.1 只在音乐里埋下：主题动机上行九个音，第十个音永远不来。）

**结构位置：** 遠化把她的处境普遍化了。她比谁都更懂“看得见、到不了”；而当难民沿着九十九折爬上来时，她也会是第一个被怀疑的。

## 4. 核心设计：歩けば、近くなる（走，就会变近）

### 4.1 从 DS 学的是什么
- 地形既是对手也是媒介：坡度、地表、水深、负重共同决定每一步；
- 负载改变身体：背上的东西有重量、有高度、会晃；
- 世界因你的行走而改变，并且记住它；
- 长时间的安静行走，被地标与音乐的出现打断。

### 4.2 已实现的系统（v0.1）

**背（背负子）**
- 货物有重量与高度；总重 ≤ 8，总高 ≤ 64px。
- 速度由负重、尾巴里的重、坡度（上坡慢、下坡快）、地表（石畳/小路快，泥慢，涉水慢）、走出来的路（越磨越快）、远化程度共同决定。
- 货堆是一个弹簧—阻尼摆：急转、起停、颠簸的地面、阵风都会推它；越高越容易晃；超过阈值，最上面的东西会掉下来（她会叫）。
- 跑步消耗体力；负重越大耗得越快。可以攀上 30px 以内的坎，但背得太重爬不上去——路线规划因此有意义。

**重（取 J / 予 K）——守恒的借贷**
- 取：把面前物体的重量吸进尾巴（最多六份）；面前没有东西时，会从背上最重的货物里取——**货物变轻，尾巴变重**：重心降低、货堆更稳，但人走得更慢。
- 予：把尾巴里的重量交给别的东西（石灯笼、地上的货物、籠丸）。
- 用途：把背不动的东西变轻背走；稳住高高的货堆；变重后可以在河底行走；（解锁后）把自己的重也交出去，变成叶子随风漂、浮在水面上。
- 尾巴满六份 → **石化**（一尊长着尾巴的小石像，不能动，必须先“予”出去）。

**路与近**
- 每一步都会在地面上磨出痕迹（草地 → 被踏实的土），走过的路更快。
- 遠化在近之岛上留下了苍白的“疤”（祠周围、断桥、奥之院石段、芒原、杉林边缘）。在这些地方行走，会把颜色——也就是“近”——一点一点走回来。
- 祠修好时，一圈“近”的波从祠向外扩散。

**远**
- 边界是“跑步机”：越靠近，脚下越打滑，最后原地踏步；画面边缘发白、抖动，远方的祭囃子变响。
- 远化的物体（大楠、完整的祠、奥之院、断掉的独木桥、停在隧道口的列车）是苍白的幻影，带视差地跟着镜头走——永远够不到。

**建造：祠的四个阶段**
| 阶段 | 需要 | 来源 |
|---|---|---|
| 其一 · 礎 | 平石 ×1 | 溪边、瀑潭下、池边（重 4：需要先取重或者慢慢背） |
| 其二 · 柱 | 柱 ×4 | 杉木段（算 2 根，重 5）／竹竿（算 1 根，重 1）／压住她的那根梁（算 2 根） |
| 其三 · 屋根 | 杉树皮 ×3 | 杉林里倒木旁 |
| 其四 · 注连＋御神体 | 葛藤 ×1，穴石 ×1 | 林缘的葛丛；瀑潭边 |

“近而重”与“远而轻”的取舍（杉木段 vs 竹竿）就是第一课的运输决策。

**供品（计数）**：九十九件供品被那一夜的风吹散到山里（v0.1 放置了 46 件、26 种）。每一种第一次捡到时，她会说出是谁、为了什么留下的——这是用物件写人的世界观。

**付丧：籠丸**：在烧炭小屋找到葛笼，把它背回祠，它会醒来，长出腿跟着你走，可以替你装东西（站在它旁边按 Q）。

### 4.3 初始台地原则在九十九折峠的落实
- **边界即事件。** 近之岛四周是远之海；你能看见岛外的山，但走不过去。离开这座岛的条件（v0.2）是让“近”延伸出去，而不是拿到一件道具。
- **地标。** 苍白的大楠与半座祠（从岛上大部分地方都看得见）、瀑布的声音、隧道口、芒原的眺望岩、奥之院的大鸟居。
- **不教学。** 第一分钟只有一个能做的动作（被梁压住 → 取）；第二个动作由第一个动作的后果逼出来（变成石头 → 予）。其余全部由可见目标、地形暗示和她的自言自语承担；按键提示只在情境中出现。
- **区域：** 峠の祠 · 九十九折旧道（石畳、地藏、丁石）· 杉林 · 沢と滝 · 竹林と炭焼き小屋 · 芒原と見晴らし岩 · 池 · 隧道口 · 奥之院への石段。

## 5. 叙事与演出

**台词规则（防 AI 腔）：** 短句；具体的物代替抽象的情绪；动作代替陈述；幽默来自人物逻辑；悲伤只做减法；不做排比，不做主题宣言，不写“仿佛……又仿佛……”。旁白全篇只出现两次。

**演出：** 电影式黑边、俯视世界中的推拉摇移镜头、侧视远景镜头（树顶上看平原、芒原眺望）、时间流逝、BotW 式的稀疏音乐（乐句之后是很长的沉默）、角色语音“音节声”（每个角色一种音色）。

**序章节拍：** 黄昏数供品（九十八、九十九）→ 对乌鸦名乗り → 三年前的瓶盖 → 入夜，坏了四十年的收音机响起祭囃子 → “声音是从四面八方来的” → 树顶远景：平原的灯一盏一盏往天上走，苍白的波从地平线压过来 → 回到峠，远化的前线扫过一切 → 「那一夜，所有的东西，都离得远了一点。」→ 标题。

**苏醒节拍：** 被梁压住（取）→ 变成石头（予）→ 苍白的大楠 → 半座祠 → “一、二、三。……三？！” → 决定把供品捡回来，顺便把家修了。

**碎片叙事：** 收音机（「远化」、不要呼唤已经走远的家人、军方否认与「隔」有关、“这里是……第七……我们还在”）；烧炭老人的日记（孙女说城里在建「隔」，往后见面要提前申请；“明天上峠，给貂大人送柿子”；十六号，他没有来）。

**第一章钩子：** 祠修好的那晚，九十九折的山脚下有一列灯笼正在往上爬——三年来第一次有人走这条路。

## 6. 技术美术

**为什么换管线：** 旧作是“3D 低模渲染成像素”。新作改为“像素精灵 + 法线/凸起深度 + 延迟光照”：画面的手工感来自精灵本身，光影的呼吸感来自动态光照。

- **相机：** 45° 斜投影正交（屏幕 = (X, Y−Z)，深度 = Y+Z），整数缩放，像素对齐 + 亚像素平移合成，镜头移动不游动。
- **地形：** 4px 网格高度场，陡坡即悬崖（自动换岩层材质，顶部草沿）；所有图案在屏幕锁定的像素坐标上计算（任何坡度上都清晰）；材质边界用抖动查找做成参差的像素边。
- **精灵：** 每个像素携带反照率、相机空间法线、凸起深度（逐像素写深度：角色可以“站进”灌木里）、材质与自发光。
- **G-buffer → 光照：** 太阳阴影图（精灵在阴影 pass 中转向太阳方位，任何太阳角度都有正确剪影）、树冠漏光斑（叶影随风摇）、云影、最多 32 个点光源（灯笼、萤火虫、她尾巴里的重量发出的光）、分段量化 + 窄抖动（保持像素画的色阶）、叶片/纸的透光、湿润高光、体积光束、贴地的山雾、遠化的褪色。
- **水：** 折射、屏幕空间反射（逐列上行步进，倒影是真的倒影）、岸边泡沫、急流白沫、雨纹、浅滩焦散。
- **远化幽灵：** 苍白蓝调色带 + 有序抖动透明 + 视差跟随镜头。
- **后期：** bloom、分段色调（暗部偏冷、高光偏暖）、暗角、胶片颗粒、黑边、远化时屏幕边缘的发白与扭动。
- **程序化像素美术：** 叶团 = 细胞化的小穹顶（剪影像手绘，受光像体积）；色带 = 色相偏移 ramp（暗部偏蓝紫，亮部偏暖黄）；人物 = 形状参数化的纸偶，逐帧合成；对话立绘 96×96，十一种表情。
- **声音（全合成）：** 风与叶、溪与瀑；按时辰出现的ミンミンゼミ、ヒグラシ（黄昏）、ウグイス（清晨）、スズムシ与カジカガエル（夜）；阳音阶主题“九个音上行，第十个音永远不来”；遠囃子（篠笛、締太鼓、大太鼓、当り鉦，低通 + 长混响 + 随风摇摆的音量与音高）。

## 8. 诚实的风险评估

1. **“近”必须是硬约束，否则只是滤镜。** v0.1 里“近”影响速度、边界和画面，但还不够“痛”。v0.3 的远化潮汐要让近度成为路线规划的约束条件。
2. **运输手感需要大量调参。** 晃动、负重曲线、攀爬阈值目前是第一版数值，应以“背着四根木头从杉林回到祠”这一条路线为基准反复调。
3. **全程序化美术的上限。** 环境、光照、系统可以靠程序达到高水准；但若目标是世界级 IP，核心角色（立绘、动作关键帧）最终需要人工像素美术介入。建议从 v0.2 起把主角动画与立绘交给人工，程序负责环境与系统。
4. **中文台词的“轻小说感”需要声线表约束。** 本次所有台词按同一份人物声线写成；后续应建立角色台本规范（自称、句长、禁用句式）。
5. **v0.1 已知局限：** 只有一个区域；没有失败状态（掉进远之海只会原地踏步）；籠丸的装载规则很简单；性能在低端手机上未调优。
