# 26 人写的台词：宫崎骏、新海诚和日式小说里的语感与幽默

> 起因：G5R2-9。用户对剧本第三版的意见（原话见 decision-log）：
> 1. 还有很强的 AI 味，比上一版好很多；婆婆不像婆婆，「今晚的鼓，你来敲」这种话人不会这么说，至少不是这个风格。
> 2. 去读宫崎骏、新海诚的台词和近几十年受欢迎的日式小说，从真实的文本里学人的语言特征、专业作家的语感。不是抄。
> 3. 剧本比 v0.1 少了很多幽默。v0.1 有乌鸦、有收音机，那种自然的、让人会心一笑的节奏，是 v0.1 做得最好的地方，后来的版本里没有了。
>
> 本文接着 knowledge/23 写。23 分析我们的台词为什么像 AI；本文看人写的台词怎么做，归纳成写法。日期 2026-10-15。研究代理只读资料、写本文，没有改剧本和游戏文件。
>
> **版权**：每部作品最多直接引两条台词（一条＝一个人说的一轮话，都很短），只用于分析，附出处；其余用自己的话转述。学的是语言特征和手法，不学情节和台词本身。
>
> **核实的标记**：
> - 【台词集】：日本的台词整理网站，主要是映画スクエア（eiga-square.jp），每条附场景说明和时间点。没有和影片字幕逐字核对，助词、标点可能有出入。
> - 【原文】：公版作品的原文页面，或学术论文的 PDF 原文。
> - 【转引】：只在别人的文章、词条、书评里读到。
> - 读不到、对不上的，列在第 8 节。
>
> **局限，先说清楚**：我没有看片，也没读到完整剧本或小说全文，读的是带场景说明的台词集、词条、书评和论文。网上找不到可靠的官方中文字幕逐句文本（能搜到的多是粉丝站转录，版本混杂），所以本文里所有的中文例句都是本文自拟，用来说明"类型"，不是官方译文，也不是给剧本的成稿。

## 0. 结论先行：五个发现

1. **长辈不派活，长辈绕。** 人写的老人几乎从不用一句干净的祈使句请人办大事。她们先喂吃的；讲先例，不讲道理；诉苦以后留半句，等对方自己接；拉第三方；或者把好意伪装成别的事。《魔女宅急便》的老妇人把送给琪琪的蛋糕说成"一单货，送给一个叫琪琪的人"。民俗学的田野记录也是这样：对马的村寄合"不讲理，把知道的先例一件件摆出来"（宫本常一）。「今晚的鼓，你来敲」是派工单的说法：没有缓冲，没有情面，没有她自己的理由。
2. **人的话有缓冲，还会自己拆台。** 新海诚的冨美说一个看法要包两层（「だからまあ……なんて思ったりもするね」）；《幽灵公主》的ジコ坊说完一句大道理，马上补一句"这是师父说的"。我们的台词句句是结论，没有一句给自己留退路，也没有一句拆自己的台。
3. **日式笑点的语用本质是"故意不合作"。** 语用学把ボケ解释为偏离会话原则、让对话进行不下去，ツッコミ把它拉回来（金水敏 1992）；中田一志（2014）说得更直白：日常对话追求效率和一致，漫才享受低效和不一致。knowledge/23 已经发现我们的台词"过度遵守"合作原则，这就是笑不出来的语用原因。要好笑，得允许人物说没用的、跑题的、不讲理的话。
4. **v0.1 好笑，是因为有一个被现实打脸的主体，和一群不会回嘴的搭档。** 自封"九十九折峠之主"的小神，三年没人上供；她对乌鸦报名号，对坏了四十年的收音机说话，给竹篮封家臣，对方的沉默和噪音就是对方的台词；演出里写死了停顿（报完名号停 1.3 秒）。第三版的主角几乎只当吐槽的一方，很少出丑；世界里没有会"不配合"的东西；笑点主要是一种机制（谈钱），三场里出现了八九句，再加上小孩大喊。
5. **中文这一头有两个坑：役割语和"浓妆"。** 日本作品里老人说「わしは〜じゃ」是虚构的"役割语"，现实的老人不这么说（金水敏）；中文里对应的是"老身""老夫""老婆子我"一类戏腔，同样不能用。另一头是把口语译成书面美文、四字格（藤井省三批评林少华译村上"浓妆艳抹"）。乡下老太太的中文要用普通口语，方言词只撒几粒，让读者自己补全。三浦しをん在《神去なあなあ日常》里就是这么做的：村里人的话大体写成标准语，再请读者想象"他们其实一直说着方言"。

## 2. 每个来源学到了什么

### 2.1 宫崎骏

#### 《となりのトトロ》（龙猫，1988）：勘太的奶奶

- 「今ごろ、天井裏で引っ越しの相談でもぶってんのかな」【台词集】[映画スクエア](https://eiga-square.jp/title/tonari_no_totoro/quotes/4)
  场景：梅的手被煤灰染黑。奶奶说那是煤灰精灵，没人住的老房子里才有；不吓人，冲它笑就不捣乱，过阵子自己就走了。说完加了这一句："这会儿大概在顶棚上开会商量搬家呢吧。"
- 「ばあちゃんの畑のもんを食べりゃ、すぐ元気になっちゃうよ」【台词集】[映画スクエア](https://eiga-square.jp/title/tonari_no_totoro/quotes/19)
  场景：小月问，这些菜能不能让住院的妈妈好起来。

学到的：
- **怪事当家常说。** 她不解释煤灰精灵"是什么"，把它说成一户要搬走的邻居，还用了村里开会的说法（相談をぶつ）。一段解释，最后落在一句玩笑上。
- **问病，答吃的。** 小月问的是母亲的病，她答的是自家的菜，顺手夸了自己的地。安慰不讲道理，落在吃上。
- **用辈分称自己。** 她说"ばあちゃんの畑"（奶奶的地），不说"我的地"。日本人对小孩说话时用亲属称谓称自己（铃木孝夫《ことばと文化》讨论过，【转引】）；中文的奶奶也说"奶奶给你拿"。
- **标准用身体，不用数字。** 教姐妹压井水，她说压到"水变凉为止"（[映画スクエア](https://eiga-square.jp/title/tonari_no_totoro/quotes/6)，转述）。
- **方言只撒几粒。** ciatr 指出她的话里混着「んだ」「〜け」，听着像东北或北关东，片里并没有设定是哪里的方言（[ciatr](https://ciatr.jp/topics/338915)）。

#### 《魔女の宅急便》（魔女宅急便，1989）：订鲱鱼派的老妇人、黑猫吉吉

- 老婦人「それをキキという人に届けて欲しいの。この前、とってもお世話になったから」【台词集】[映画スクエア](https://eiga-square.jp/title/majo_no_takyubin/quotes/19)
  场景：结尾，老妇人烤了一个画着琪琪的巧克力蛋糕，托琪琪"送给一个叫琪琪的人"，还请她打听"那个人"的生日，好再烤一次。琪琪忍着眼泪，顺着这个说法回答：那孩子一定也想知道您的生日。
- 吉吉假扮成玩偶猫，琪琪叫它别动；吉吉问"那呼吸呢？"，琪琪答：「できるだけしないで」【台词集】[映画スクエア](https://eiga-square.jp/title/majo_no_takyubin/quotes/8)

学到的：
- **好意伪装成订单。** 老妇人知道琪琪是送货的，就用"下单"的说法把礼物递过去；琪琪也不拆穿，用同一个说法把感谢递回去。两个人谁都没说"谢谢""喜欢你"。我们的小鹊收礼会不安（knowledge/23 §6.1），人对付这种人，办法就是把礼物包成一单生意。这是手法，不要照搬情节。
- **冷面接梗。** 吉吉把"别动"推到荒谬处，琪琪不纠正，认真地给出一个荒谬的答案。笑点在第二句的认真。
- **吐槽落在具体后果上。** 看到积满灰的阁楼，吉吉说"明天我大概就变成白猫了"（[/6](https://eiga-square.jp/title/majo_no_takyubin/quotes/6)，转述）；护巢的乌鸦不让他们靠近，吉吉叹气：魔女也落魄了，乌鸦从前是魔女的仆人（[/7](https://eiga-square.jp/title/majo_no_takyubin/quotes/7)，转述），琪琪回一句"那是很久以前的事了"。它从不评论琪琪的心情。顺带：这是一个乌鸦笑话。

#### 《千と千尋の神隠し》（千与千寻，2001）：锅炉爷爷、钱婆婆

- 釜爺「ただのススに戻りてえのか！」【台词集】[映画スクエア](https://eiga-square.jp/title/sen_to_chihiro_no_kamikakushi/quotes/4)
  场景：千寻救了一只被煤块压住的煤灰精灵，别的精灵见状纷纷装晕，想让她替它们搬。锅炉爷爷吼它们："想变回普通的煤灰吗！"
- 銭婆「ほら、あの人、ハイカラじゃないじゃない。魔女の双子なんて厄介の元ね」【台词集】[映画スクエア](https://eiga-square.jp/title/sen_to_chihiro_no_kamikakushi/quotes/15)
  场景：千寻把白龙偷走的契约印章还给钱婆。钱婆接过印章，先说"我们俩合起来才算一个人，偏偏合不来"，接着是这句。

学到的：
- **吓唬是量身定做的。** 骂煤灰精灵，就拿"变回煤灰"吓它们，具体，而且只对它们有效（对照后面《ゴーシュ》的"狸汤"）。
- **大事当前说家长里短。** 印章被偷、白龙重伤，钱婆先抱怨双胞胎妹妹不时髦。「ほら」「じゃない」「ね」都是把对方拉到自己这边。老太太在要紧的时候说不要紧的话，要紧的事反而放轻了。
- 片里孩子的话（转述）：坊威胁汤婆婆"你要是把千弄哭了，我就讨厌婆婆了"；千寻对变成猪的父母说"别吃太胖，会被吃掉的"。孩子的威胁和安慰都按孩子的逻辑走，好笑，也心酸。

#### 《崖の上のポニョ》（崖上的波妞，2008）：养老院的トキ、理纱

- トキ「はやく海に戻しとくれ。津波を呼ぶよ」【台词集】[映画スクエア](https://eiga-square.jp/title/gake_no_ue_no_ponyo/quotes/3)
  场景：宗介把波妞拿给隔壁养老院的老太太们看。トキ一见就说是人面鱼，快放回海里，会招来海啸；波妞朝她喷了一脸水。トキ平时嘴硬，藏着对宗介的喜欢，后来是她一把抓住了宗介。
- 丈夫临时不能回家，船经过时用灯打信号说爱她；理纱喝着啤酒，用灯回了四遍「BAKA」【台词集】[映画スクエア](https://eiga-square.jp/title/gake_no_ue_no_ponyo/quotes/6)

学到的：
- **刀子嘴。** 老太太的命令带老派的「〜とくれ」，迷信脱口而出；关心藏在嫌弃里。
- **让东西替人说话。** 理纱生气不开口，用信号灯骂。媒介本身就是笑点。v0.1 的收音机是同一类。

#### 《ハウルの動く城》（哈尔的移动城堡，2004）：变老的苏菲、火恶魔卡西法

- ソフィー「年を取っていいことは、驚かなくなることね」【台词集】[映画スクエア](https://eiga-square.jp/title/howl_no_ugoku_shiro/quotes/6)
  场景：被诅咒变成老太太的苏菲走进会走路的城堡，在火炉边坐下取暖，自言自语。
- 卡西法说它讨厌火药的火：「奴らには礼儀ってものがないからね」【台词集】[映画スクエア](https://eiga-square.jp/title/howl_no_ugoku_shiro/quotes/8)
  场景：哈尔打完仗回来，一身焦糊味，讲战场有多惨，卡西法这么接。

学到的：
- **最该吃惊的时候不吃惊。** 这句话像格言，但它是反应，落在一个荒谬的处境里（坐在一座会走的城堡里，对着一团会说话的火），所以好笑。我们禁格言，禁的是"总结"，这种"反应"另当别论（第 4 节）。
- **非人的东西有自己的价值观。** 火嫌火药的火没礼貌；v0.1 的小神骂乌鸦"一枚瓶盖都没供过"。用它自己的尺度量世界，它就有了人格。

#### 《もののけ姫》（幽灵公主，1997）：ジコ坊、タタラ场的トキ

- ジコ坊「肝心なことは、死に食われぬことだ。いや、これは師匠の受け売りだがな」【台词集】[映画スクエア](https://eiga-square.jp/title/mononokehime/quotes/8)
  场景：阿席达卡杀了人，后悔下山。ジコ坊对他说的。
- 阿席达卡问踩风箱的女人们苦不苦。トキ先拖一句「そりゃあさ……」，再说比外面强多了，最后一个「ねぇ」把旁边的女人拉进来；旁边的女人接着说吃得饱、男人不敢欺负（[映画スクエア](https://eiga-square.jp/title/mononokehime/quotes/19)，摘词）。

学到的：
- **格言要自己拆台。** 说完大道理，马上承认是师父的话。这一拆，说话的人就从"作者的传声筒"变回一个人。
- **不顺的回答有延迟、让步、拉帮手。** 会话分析叫"非优选应答"（knowledge/23 §2.2c）。トキ一句话里全有了。说的好处是吃饱和不挨欺负，都是身体上的事。

#### 高畑勲《おもひでぽろぽろ》（岁月的童话，1991）

- タエ子の祖母「長生きするといろんな経験するよ」【台词集】[映画スクエア](https://eiga-square.jp/title/omoide_poroporo/quotes/1)
  场景：妙子五年级，求爸爸买来一整个菠萝。全家吃了，又难吃又尴尬，饭桌上没人说话；六十七岁的奶奶在沉默里嘟囔了这一句。
- ばっちゃん「オレは悪かったと思ってねえよ」【台词集】[映画スクエア](https://eiga-square.jp/title/omoide_poroporo/quotes/16)
  场景：山形农家的老太太在妙子回东京前一晚，突然问她愿不愿意嫁给敏夫，妙子跑了出去。家里人数落老太太，她这么回。

学到的：
- **大词套小事。** "活得久了，什么都能经历"，用在一个难吃的菠萝上。老人最典型的冷幽默：拿一辈子的分量去压一件小事，顺手替全家解了围。
- **真实的乡下老太太自称「オレ」。** 在东北方言里，老太太说「おれ」「おら」很平常（这一点是常识，未单独核实），跟役割语里老人的「わし」、老太太的「あたし」都不一样（§2.6）。写真人，要的是这种出人意料的真。
- **嘴硬，不认错。**

#### 高畑勲《平成狸合戦ぽんぽこ》（平成狸合战，1994）

- 正吉「なぜかタヌキおやじと呼ぶんですよね、人間は。変ですねえ」【台词集】[映画スクエア](https://eiga-square.jp/title/heisei_tanuki_gassen_pom_poko/quotes/12)（摘句；前半是"像那个社长那样的人"）
- 狸们馋人类的吃食，一口气报菜名：汉堡、甜甜圈、炸鸡、薯片……最后一个是"鸡"（[/5](https://eiga-square.jp/title/heisei_tanuki_gassen_pom_poko/quotes/5)，转述）。旁白一本正经：选派长途使者时没人报名，"全体决定装狸睡"（タヌキ寝入り，[/3](https://eiga-square.jp/title/heisei_tanuki_gassen_pom_poko/quotes/3)，转述）。

学到的：
- **局外人看人话。** 狸议论"狸老爹"这个人类说法，好笑在角度。v0.1 的小神管火车叫"铁的蛇"、管收音机叫"铁匣子"，是同一招。
- **列举的最后一项出格**（三段オチ，第 4 节）。
- **旁白可以面无表情地说双关。** 但双关过不了语言关（第 6 节）。

### 2.2 新海诚

#### 《君の名は。》（你的名字。，2016）

- 一葉「おや、三葉。あんた今、夢を見とるなあ？」【台词集】[映画スクエア](https://eiga-square.jp/title/kimi_no_na_ha/quotes/11)
  场景：去山顶神体供完口嚼酒，黄昏下山。孙女的身体里其实是瀧，他停下来看小镇；奶奶看出来了。
- 三葉「来世は東京のイケメン男子にしてくださーい！！」【台词集】[映画スクエア](https://eiga-square.jp/title/kimi_no_na_ha/quotes/4)（前面还有两句：这种小镇我受够了！这种人生我受够了！）

另外，一葉讲"结（ムスビ）"的两段（[/9](https://www.eiga-square.jp/title/kimi_no_na_ha/quotes/9)、[/10](https://www.eiga-square.jp/title/kimi_no_na_ha/quotes/10)，转述）：先是一串动词（聚拢、成形、拧、缠、往回走、断、再接上），然后"这就是结，这就是时间"；水、米、酒进了身体，和魂结在一起，也叫结，所以今天的供奉是要紧的规矩。这是全片最像"说明"的台词，而且是排比。场景：领着两个孙女往山里的神体走，路上先问她们"知道什么叫ムスビ吗"；孙女的身体里其实是瀧，真不懂，只回了一句"ムスビ？"。

学到的：
- **老人撞见怪事，用「おや」开头。** 语气像问"吃了没"，不惊不叫，不追问。我们的婆婆说起屋里的座敷童子、说起小鹊不老，都该是这个温度。
- **少女的笑点，是把心里话喊给神明听。** 具体（东京、帅哥、下辈子），夸张，求的东西又小又俗。
- **说明躲不开的时候。** 新海诚把"结"的讲解交给一个爱讲古的老人，用方言，放在走山路这件正在做的事里；她先提问，听的人有真不懂的理由（换了身体的城里男孩），还回了一句糊涂的"ムスビ？"。这就避开了"两个人互相讲彼此早就知道的事"（knowledge/23 §2.2a）。我们的世界规则如果非由人说出来不可，也要满足这三条：说的人本来就爱念叨，手上有事，听的人真不知道。

#### 《天気の子》（天气之子，2019）

- 冨美「だからまあ、元に戻っただけだわ。なんて思ったりもするね」【台词集】[映画スクエア](https://eiga-square.jp/title/2019_tenki_no_ko/quotes/28)
  场景：三年后，东京一部分被水淹了，她搬了家。帆高来看她，她讲两百年前这一带本来是海湾，是人和天气一点点改过来的，然后是这一句。她当初请"晴女"，是为了亡夫的初盆（[/10](https://eiga-square.jp/title/2019_tenki_no_ko/quotes/10)）。
- 安井（老刑警）对须贺：「あなた今、泣いてますよ」【台词集】[映画スクエア](https://eiga-square.jp/title/2019_tenki_no_ko/quotes/22)

学到的：
- **一个看法包两层。** 「だから**まあ**」……「だけ**だわ**」……「**なんて思ったりもする**ね」。老人的看法被"也就是""我有时候会这么想"裹起来，说得轻，分量反而重。AI 写的老人只会下结论。
- **拿很长的时间去量眼前的事。** 两百年前是海，所以淹了也只是回到原样。老人不跟你讲道理，跟你讲从前。
- **观察代替安慰。** 不说"别难过"，只说"你在哭"。
- **盂兰盆的请求背后有一个具体的死者。** 冨美的初盆，和我们的序章是同一个节令（第 3 节会用到）。

#### 《すずめの戸締まり》（铃芽之旅，2022）

- 环问四岁的铃芽「うちの子になる？」；后来铃芽对猫一样的大臣说了同一句【转引】[ciatr](https://ciatr.jp/topics/320926)。
- 芹泽说草太：「あいつは自分の扱いが雑なんだよ」【转引】[ciatr](https://ciatr.jp/topics/320926)

学到的：
- **同一句话换个人说，意思就变了。** 回声比解释有力。
- **用"对待东西"的说法评价人。** "他太不爱惜自己"是说明；"他使唤自己使唤得太糙"是朋友的嘴（中文为本文自拟）。
- 变成椅子的草太，没有找到可核实的台词，不分析。

### 2.3 细田守《サマーウォーズ》（夏日大作战，2009）：九十岁的阵内荣

- 栄「これは、あんたにしかできないことなんだ。あんたならできる。できるって」【台词集】[映画スクエア](https://eiga-square.jp/title/summer_wars/quotes/9)
  场景：网络世界大乱，她一个接一个给旧学生和熟人打电话鼓劲。
- 栄の遺言「一番いけないのは、おなかが空いていることと、1人でいることだから」【台词集】[映画スクエア](https://eiga-square.jp/title/summer_wars/quotes/15)

学到的：
- **劝人靠重复。** 「できる。できるって」，第二遍没有新信息，只是在背后推一把。
- **老人的价值观落在身体上：饿，和一个人待着。** 她去世后，家里人说的是：先去给奶奶好好打个招呼，然后大家一起吃饭（[/16](https://eiga-square.jp/title/summer_wars/quotes/16)，转述）。"人齐"和"吃饭"是一回事。我们的婆婆"一辈子操心人齐不齐"，这个症状在嘴上就该是这个样子。

### 2.4 小说

#### 森見登美彦《有頂天家族》（有顶天家族，2007）

- 父亲的遗训「面白きことは良きことなり！」【转引】[日文维基](https://ja.wikipedia.org/wiki/有頂天家族)
- 弁天对狸矢三郎说「食べちゃいたいほど好きなのだもの」【转引】同上。书里的"星期五俱乐部"每年忘年会吃狸火锅，矢三郎的父亲就是这么死的。
- 赤玉先生（如意ヶ嶽薬師坊）：从前是呼风唤雨的大天狗，失势后飞不起来，住在出町商店街后面的破公寓，照样目中无人；暗地里喜欢照顾他的矢三郎（日文维基，转述）。

学到的：
- **自大与现实的落差能撑起一个人物。** 赤玉先生是 v0.1"本座"的远亲：架子越大，处境越寒酸，越好笑，也越可怜。
- **把惯用语按字面落实。** "喜欢得想吃掉你"，从一个真会吃狸的人嘴里说给狸听。话还是那句话，意思全变了。
- **家训是人物的护身符。** "有趣就是好事"是父亲留下、矢三郎挂在嘴上的话。它从人物嘴里说出来，不是旁白替作者宣布的主题。

#### 森見登美彦《夜は短し歩けよ乙女》（春宵苦短，少女前进吧！，2006）

- 黑发少女的拿手好戏：万能咒语「なむなむ！」，和姐姐传授的"朋友拳"；前辈设计的"偶遇"一次次发生，她每次都说「奇遇ですねえ！」【转引】[KAI-YOU](https://kai-you.net/word/%E5%A4%9C%E3%81%AF%E7%9F%AD%E3%81%97%E6%AD%A9%E3%81%91%E3%82%88%E4%B9%99%E5%A5%B3)
- 前辈管自己的追求叫"一天天填她这座城的外护城河"，作战计划叫"ナカメ作戦"（尽量让她看见我）（同上，转述）。井上ひさし在直木赏选评里称赞它故意用恶趣味夸大青春小说自以为是的青涩，彻底嘲弄青春小说里"巧遇"的方便安排（宫泽菜那的论文转引，[富山大学](https://toyama.repo.nii.ac.jp/record/14379/files/HikakuBungaku_09_01-10_Page172to199.pdf)）。

学到的：
- **口头禅是人物自己的小仪式，不解释。** 没有人问"なむなむ"是什么意思。
- **观众知道、她不知道。** 偶遇是安排好的，她真心觉得巧。同一句"好巧啊"每重复一次，笑点就大一点（天丼）。
- **一本正经的大词用在小事上**（护城河、作战），是森见的招牌，也是 v0.1"吾乃……是也"的路数。

#### 三浦しをん《神去なあなあ日常》（2009）、《舟を編む》（编舟记，2011；电影 2013）

- 《神去》的叙述者（城里来的少年）请读者：「住人は本当は、しじゅう神去弁でしゃべっているのだと思って読んでほしい。」【转引】读者论坛引文，标第 24 页（[Natively](https://forums.learnnatively.com/t/informal-reading-club/7393)），没有和原书核对。
- 书名里的「なあなあ」是村里人的口头禅，意思近于"慢慢来""先别急"，引申为风和日丽、过得舒坦（[日文维基](https://ja.wikipedia.org/wiki/神去なあなあ日常)）。台湾版保留了这个音，书名作《哪啊哪啊神去村》（见诚品等书店的商品列表）。
- 电影《编舟记》：老辞典编纂家松本先生和马缔在快餐店偷听女高中生聊天，女孩们嫌这两个怪人恶心。松本问「"キモい"は採集済みですね？」，马缔答「もちろんです」【台词集】[映画スクエア](https://eiga-square.jp/title/fune_wo_amu/quotes/16)

学到的：
- **方言少放，请读者自己补。** 村里人的话大体写成标准语，只留几个词，再让叙述者告诉读者"其实他们一直说方言"。中文版也该这么做（第 6 节）。
- **一个村子一个口头禅。** 「なあなあ」一个词带出整个村子的脾气，外来人一开始听不懂。
- **执念把侮辱变成工作素材。** 被人当面嫌恶心，老学者关心的是这个词收了没有。身份和执念压过了情绪，笑点就在这里。我们的小鹊"把一切变成运货"，最好笑的用法也是这样：在本该动感情的地方，她认真地处理"货"。松本先生临终的信里说，若真有那个世界，他打算到那边去采集用例（[/18](https://eiga-square.jp/title/fune_wo_amu/quotes/18)，转述）。执念到死都在，好笑，也心酸。

#### 梨木香歩《西の魔女が死んだ》（1994）

- 舞说"外婆，我最喜欢你了"，外婆的回答总是「アイ・ノウ」【转引】[honcierge](https://honcierge.jp/articles/shelf_story/7474)
- 舞睡不着时，外婆念「ナイ、ナイ、スゥイーティー」（同上）。

学到的：
- **最短的回答装最多的东西。** 不说"我也爱你"，说"我知道"。答得不对称，所以动人。
- **一个人的语域要有来由。** 这位外婆是英国人，说话用敬体，讲道理时会用三连比喻（仙人掌不必长在水里，莲花不在空中开，北极熊……，同上）。书面腔放在她身上不违和：她是外国人、讲究人，正在教外孙女"魔女修行"。放到我们的山村婆婆身上就不行。

### 2.5 公版作品、曲艺与田野记录（本文加的）

#### 夏目漱石《坊っちゃん》（1906）：老女佣阿清

- 「何を見やげに買って来てやろう、何が欲しい」と聞いてみたら「越後の笹飴が食べたい」と云った。越後の笹飴なんて聞いた事もない。第一方角が違う。【原文】[维基文库](https://ja.wikisource.org/wiki/坊っちゃん)

学到的：
- **老人的疼爱：吃的，无来由的夸，奇怪而具体的愿望。** 阿清用自己的零花钱给他买金锷、红梅烧（同上）；问她要什么土产，她点名要一样谁也没听过的糖。

#### 宮沢賢治《セロ弾きのゴーシュ》（1934）：夜里来练小鼓的狸子

- 高修吓唬它"知道什么叫狸汤吗"，狸子答：「狸汁ってぼく知らない。」【原文】[秋田魁新报](https://www.sakigake.jp/special/2020/meisaku-natsu/gauche/page_02.jsp)

#### 落语《時そば》《まんじゅうこわい》（传统段子，演者之间说法不同）

- 《時そば》：吃完荞麦面付十六文，一文一文数，数到八，问"现在几更了？"，摊主答"九"，他接着"十、十一……"数完，少付一文。旁边学样的人第二天照做，摊主答"四"，他从五接着数，反倒多付了（[HugKum](https://hugkum.sho.jp/514207)，转述）。

### 2.6 研究文献（用来校准）

- **金水敏：役割语。** 听到一种说法就能想起一种人物形象，这种说法叫役割语。「首都圏に住む老人はまず「わしは知っておるんじゃ」のような〈老人語〉を話しません」；〈老人語〉是二百五十多年前的江户时代形成的；役割语在绘本、漫画、动画、电影、小说里最起作用，能让读者一下子认出人物（[国际交流基金](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/research/201302.html)）。**结论**：写真人，不用役割语；只有人物在"演"的时候才用（v0.1 的"本座"）。
- **金水敏 1992、中田一志 2014：ボケ与ツッコミ的语用学。** 金水把ボケ说成偏离会话原则（Grice 的合作原则）、让会话进行不下去，ツッコミ把它拉回来。中田在此基础上说：日常对话追求效率和一致，漫才享受低效和不一致；ボケ是让系统出错的操作，ツッコミ是重启系统的命令（中田一志「漫才の笑い：エラーと非効率性と非整合性」『日本語・日本文化』41，2014，【原文】[大阪大学](https://ir.library.osaka-u.ac.jp/repo/ouka/all/50778/JLC_41_001.pdf)）。**结论**：knowledge/23 发现我们的台词"过度遵守"合作原则，这就是笑不出来的语用原因。
- **高扬 2020：拒绝与再请求。** 日语教材里的拒绝多是「〜はちょっと…。」「それが…。」这类说一半的形式；委婉的拒绝反而可能招来对方再请求；"先拒后受"要经过几个来回（高揚「再依頼から合意形成に至る断りの談話の展開構造」『国際日本研究』12，2020，【原文】[筑波大学](https://tsukuba.repo.nii.ac.jp/record/54318/files/JIAJS_12-155.pdf)）。**结论**：第 0 场"小鹊推说看天色，婆婆再推一把"，这个骨架是对的；错在婆婆的第一句请求太直。
- **白川博之 2009《「言いさし文」の研究》**：只说从句、不说主句的句子，是日语里成体系的表达。王紫莹（王紫瑩）的日中对照综述在"中途终了文"的定义部分专门介绍了它【转引】（[城西国际大学](https://www.jiu.ac.jp/files/user/graduate/human/publish/pdf/lcr4_10_paper.pdf)；PDF 的正文字体无法渲染，只读到标题和章节名，内容据检索摘要）。
- **文雪 2018《役割語の翻訳手法》（大阪大学博士论文）**：文学译本里，译者自己的文风常常压过角色的说话方式；漫画译本常常不对应角色的语言特征；第四章专门分析了中文译本（《海边的卡夫卡》）里的四字格对人物形象的影响；方言是中文役割语的重要资源（【原文】[论文要旨](https://ir.library.osaka-u.ac.jp/repo/ouka/all/69699/29942_Abstract.pdf)）。
- **藤井省三与林少华之争**：藤井认为村上春树用的是口语体，好的译本要最大限度传达这种文体，林译却是"文语体、书面语体"；赖明珠的译本"不化妆，保留本来面目"，林译"浓妆艳抹"。林少华的回应：文学翻译不存在直译，"译文读出来不要像翻译体"（石剑锋，东方早报，【转引】[爱思想](https://www.aisixiang.com/data/80311.html)）。**结论**：两人各指出了一种失败，译制腔和浓妆。我们两头都要躲。
- **术语**：
  - 天丼：「同じことを2度またはそれ以上繰り返すことで滑稽な効果をもたらす」（[Weblio 转载维基](https://www.weblio.jp/content/天重)）。
  - ノリツッコミ：吐槽的一方先顺着ボケ说下去，说到一定程度再吐槽收尾（[日文维基「漫才」](https://ja.wikipedia.org/wiki/漫才)）；同一条目说中国的对口相声和二人漫才形式相近。
  - 相声讲究"三番四抖""铺平垫稳"（[界面](https://m.jiemian.com/article/2525115.html)、[中国非遗网](https://www.ihchina.cn/project_details/19234.html)只列为规律，没下定义；一般理解为铺垫三次，第四次抖包袱）。

## 3. "婆婆的嗓音"指南

### 3.1 先对齐三件事

**她多大、叫什么。** 剧本写"庄屋的主妇，五十多岁"，台词也是五十多岁的利落主妇的口气；中文里"婆婆"让人期待六七十岁以上的老太太。用户说她"不完全像一个婆婆"，一部分原因就在这里。两个办法：
- (a) 她就是老太太：庄屋当家的母亲，七十上下。"我嫁过来那年你就这个样子"相应改成"我头一回见你那年"之类（小鹊三十年前才在峠上醒来，时间要对得上）。
- (b) 保留五十多岁，称呼改成婶子、老板娘一类。

推荐 (a)：用户已经把她听成婆婆，而且下面这些老太太的说话特征更有用。这会改到人设和事实表，由主管决定是否进下一轮提案。

**她要什么。** 事实表写了"一辈子在操心人齐不齐"，台词里没有一句漏出来。"人齐"这个症状在嘴上的样子：点人头；念叨谁没来；给不在的人留一碗、留一盏；对看不见的小的说话；送り盆那天念叨要送走的亡人（盂兰盆十六日正是送祖先回去的日子，参照冨美为亡夫初盆请晴女）。第十盏灯"老规矩"，也可以从她这里得到一个人的解释，比如"宁多一盏，不少一盏"，谜面就不再像作者埋下的。这些只是方向。

**这一场装了多少事。** 第 0 场十八句台词里塞了约十个信息点：十盏灯、供品、桃、运费、不老、座敷童子、阿松、鼓、送火的顺序、拽下山。每句都在干活，就没有一句闲话。人说话总有不少闲话：寒暄、抱怨天热、抱怨膝盖、说吃的。建议把信息点砍到三四个，其余交给东西和动作：鼓台在背景里搭，院子里有人把鼓敲得稀烂，鼓槌塞在包袱里，等等。

### 3.2 乡下老太太说话的十二个特征

每条：特征，出处，中文里的样子（例句类型，本文自拟）。

1. **先喂，再说事。** 龙猫的奶奶用菜安慰人；阿清用零花钱买点心；阵内荣的遗言是"饿着和一个人待着最要不得"。
   中文："先喝口水。""黄瓜在井里冰着呢，自己捞。"
2. **讲先例，不讲理由。** 宫本常一：不讲理，把知道的事例一件件摆出来；冨美用"两百年前是海"看眼前的大水。
   中文："那年阿松他爹也闪过一回，你猜谁顶上去的？"
3. **请求拐弯。** 诉苦以后留半句，等对方接（言いさし）；或者把好意包成别的事（魔女宅急便的老妇人）；被婉拒，就再推一把（高扬 2020）。
   中文："阿松那腰哟……鼓台倒是搭好了……"（看着她，不往下说）
4. **当作已经定了。** 老人常跳过"你愿不愿意"，直接说成定局，再拿歪理堵你。
   中文："你也没说不敲啊。"
5. **软化，拉人附和。** 冨美的「まあ」「なんて思ったりもするね」；トキ的「そりゃあさ……ねぇ」；钱婆的「ほら」「じゃない」。
   中文："也就是……""我看哪……""你说是不是？""可不嘛。"
6. **怪事当家常说。** 龙猫的奶奶说煤灰精灵在顶棚上开会商量搬家；一叶用「おや」开头看穿孙女身体里换了人；冨美说"天上是另一个世界，从来如此"。
   中文："那小的今儿高兴，随它闹。"
7. **拿身体和年纪自嘲。** 变老的苏菲嫌这身子不听使唤（[映画スクエア](https://eiga-square.jp/title/howl_no_ugoku_shiro/quotes/5)，转述）。要说具体的部位：膝盖、牙、耳朵、眼神。
   中文："我这膝盖比天上的云还准，今晚准有风。"
8. **标准用身体，不用数字。** 龙猫的奶奶：压到水变凉为止。
   中文："煮到筷子插得进去。""你背着它，喘不上气了就歇。"
9. **用辈分称自己，给人起昵称。** 龙猫的奶奶说"奶奶的地"；《编舟记》的房东老太太叫马缔"みっちゃん"（[/5](https://eiga-square.jp/title/fune_wo_amu/quotes/5)）。
   中文："婆婆还能骗你？"对小鹊有一个固定的、只有她叫的叫法。
10. **重复，跑题，自说自话。** 阵内荣「できる。できるって」；钱婆在印章失而复得的时候抱怨妹妹不时髦。
    中文："你说这……你说这事闹的。"
11. **嘴硬心软，反话。** トキ嫌波妞、心里疼宗介；山形的老太太"我可不觉得我说错了"。
    中文："谁稀罕你来。"（然后多摆一副碗筷）
12. **大词套小事。** "活得久了，什么都能经历"，说的是一个难吃的菠萝。
    中文：一件小事上来一句"活了这把岁数……"，后面接的是很小的事。

**她不会说的：**
- 役割语："老身""老婆子我""哎呀呀我的乖乖"。
- 一句总结人生的格言（除非马上被自己拆掉，见 2.1 ジコ坊）。
- 日程表式的交代（"送火一点上就开跳"）。
- 路标式的转场（"对了，……"），除非是她憋了半天、假装随口一提，而且要演出来。
- 句句都对着剧情。

### 3.3 「今晚的鼓，你来敲」：为什么不像人，人会怎么说

为什么不像：
1. **言语行为太直。** 请一个不归她管的人，当着全村去敲盆鼓，这是大请求，面子上的成本高。中日两边的长辈遇到这种请求都会绕：诉苦、讲先例、找第三方、拿吃的，或者当作已经定了。干脆的祈使句留给小事、急事，或者自家不会拒绝的小辈。
2. **句法。** "今晚的鼓，你来敲"是"话题＋逗号＋短评述"，和被否掉的「今年的囃子，近」同一个家族；没有语气词（吧、呗、啊），没有情态（就、得），听起来像派工单。
3. **"对了"是作者的转场。** 这是她今天最想说的事，却用"对了"假装顺口一提。人确实会这样，但那是装出来的随口，要演出来：她憋了半天，终于开口，眼睛不看人。剧本里没有这个"憋"。
4. **理由是给玩家的。** "阿松的腰又犯了"交代了缺鼓手，没交代为什么偏偏找小鹊。人会给一个只有她们俩懂的理由（她手稳？那年替过？力气大？），或者干脆不给理由，用情面压。
5. **她真正想要的一点没漏出来。** 她要的是人齐、是盆里那点念想，台词里只剩缺人手。

人会怎么说。下面四种类型，各给一个示意（本文自拟，不是成稿）：

- **（一）诉苦，留半句。**
  「阿松那个腰哟，一早扛竹竿，'嘎'一声，人就趴地上了。」
  「鼓台倒是搭好了……」（看着她，不往下说了）
  请求不出口，等对方接。小鹊可以装傻，这正好给了她一个喜剧位置。
- **（二）当作已经定了，拉第三方。**
  「我跟会里说了，今年的鼓是你的。」
  「我几时答应的？」
  「你也没说不敲啊。」
  老人的歪理，好笑，也真。
- **（三）讲先例。**
  「那年阿松他爹摔了腿，是他媳妇顶上去的。一个女人家，敲了一宿，第二天胳膊都抬不起来。」
  「……我就是说说。」
  宫本常一说的"不讲理，摆事例"。"我就是说说"是否认（knowledge/23 §3）：越说不要紧，越要紧。
- **（四）东西代替话。**
  （婆婆把一对鼓槌塞进包袱，跟供品搁在一块儿。）
  「顺路。」
  墓在山上，鼓台在院子里，根本不顺路。这就是"最后半句落地"（参照阿清的"方向就不对"）。鼓槌还能跟着她上山，在后面的场次里继续"说话"。用不用、怎么用，主管定。

不管选哪种，小鹊的回应别再是"工钱怎么算"。谈钱这个机制在第三版里已经用得太多了（第 4、5 节）。

## 4. "幽默"指南

### 4.1 v0.1 为什么好笑

先看原文（`legacy/v0.1/src/story.js`）：

- 序章开头，她数供品：「……九十六。九十七。」「九十八。」（四下看，找到一个瓶盖）「——九十九。」「好。今天也是九十九。」
  数不够，就拿一个瓶盖凑数，还很满意。没人看见的小作弊。
- 一只乌鸦落下来。「吾乃九十九折峠之主，葛笼是也！」→ 停 1.3 秒 →「……这种时候，你应该鼓掌。」→ 乌鸦叫一声飞走 →「没礼貌。一枚瓶盖都没供过的家伙。」
  - 对一只乌鸦报名号：大和小的落差。
  - 1.3 秒的沉默就是乌鸦的台词。
  - "你应该鼓掌"：她亲口说出了自己的欲望，她想要观众。
  - 骂人用的是她自己的计价单位，瓶盖。这个单位又暴露了她有多穷。
- 「上一个走这条路的人，是三年前的夏天。」「留下这个瓶盖，许愿说想变瘦。」「……这个愿望有点难。本座还在考虑。」
  冷清（三年没人来），接一个很具体的人间愿望（想变瘦），再接神明的官僚作风（考虑了三年）。悲和笑出自同一件事。
- 收音机：「……嗯？」 铁匣子「……沙……沙沙……」「你不是四十年前就坏了吗。」
  对一台坏机器说话，噪音就是回答。"四十年前"这个数字很具体。
  之后这台收音机成了贯穿的天丼（`STORY.radio`）：先是沙沙声（"你到底收的是哪个台？"），然后是远化的新闻，"请不要呼唤已经走远的家人"，军方否认与「隔」有关，最后是"这里是第七……我们还在……"，她喊"喂？""喂！"，只剩沙沙声。同一个笑话，一次比一次不好笑，最后变成哭。
- 醒来：「……重。」「好重。哪个混账把柱子扔在本座身上了。」被压在梁下，还在摆谱。
- 「一、二、三。」「……三？！」「本座的九十九呢！」：三段，最后一拍是"本座的"。
- 捡到一只竹篮：「……和本座同名。」「那就是本座的家臣了。」歪理。
  篮子醒了：「从今天起，你叫籠丸。本座的家臣，第一号。」 籠丸「咔哒。」「……第一号也是唯一一号。不许骄傲。」最后半句落地。
- 供品的注释：糖果罐「里面的糖……被老鼠吃了。是老鼠。」；酒壶「空的。……不是本座喝的。是风。」没人问，她先否认，而且跨物件重复（天丼）。烟斗「烧炭的老爷爷每年春天来抽一斗，说是供给本座的。烟都是他自己抽了。」弹珠「……我到现在还欠他一个晴天。」
- 地藏：「……还是不说话。好习惯。」夸对方的沉默，等于拿这种"一个人对着不会回嘴的东西说话"的形式本身开玩笑。

v0.1 的设计文档自己写过原理（`legacy/v0.1/DESIGN.md` 第 72、135 行）："**性格矛盾**：浮夸的名乗り × 一个三年没有收到新供品、被铁路隧道绕过的路边小神。幽默来自人物逻辑……悲伤只做减法。"

归纳起来，v0.1 好笑靠五样东西：
1. **一个有欲望的主体被现实打脸。** 所有笑话都从同一个欲望里出来：她想被供奉，想被承认。
2. **不会回嘴的搭档。** 乌鸦、收音机、地藏、竹篮。对方的沉默和噪音由演出给出，她一个人又逗又捧（一人ボケツッコミ）。
3. **节拍写进了演出。** 名乗り后停 1.3 秒；数数分三拍。
4. **小而具体。** 瓶盖，想变瘦，坏了四十年，欠一个晴天。
5. **笑和悲同源。** 最好笑的东西底下压着最冷清的事实。

### 4.2 第三版为什么不好笑

- **主角只当吐槽的一方。** 已批准的人设写她"内里小心眼、爱恶作剧"，喜剧分工是"冷面的装傻与吐槽，一本正经地使坏"。第三版只用了吐槽，几乎不让她装傻、出丑、使坏（道祖神那一下换团子是例外，可惜没做完）。
- **世界里没有会"不配合"的东西。** 没有乌鸦，没有收音机；狸囃子原样学她哼歌，本来是个现成的搭档，只用来制造诡异。
- **机制单一。** 谈钱（运费、工钱、雇、房租、记账）在第 0、10、11 场出现了八九句；剧本自查时改成了"三种说法"，机制还是同一个。剩下的笑点多是さぢ大喊。
- **没有写停顿。** 全稿只有一处"停了两拍"。
- **信息塞得太满。** 每句都在交代，没有余地让人物说一句没用的、好笑的话。

### 4.3 手法：是什么，人写的例子，为什么好笑，《天岸》里的情境类型

只写手法和情境类型，不写成剧本。

1. **一个人又逗又捧：对着不会回嘴的对象说话。**
   - 例：v0.1 对乌鸦、地藏说话；钱婆对刚认识的孩子抱怨妹妹。
   - 原理：对方的沉默就是吐槽，由演出给出。
   - 情境类型：小鹊对身旁空位说话（已批准的习惯）。不只用来伤感，也用来告状、请示、算小账，空位当然不回答，她替空位点头。还有对戴笠的道祖神讨价还价。
2. **不会说话的捧哏：动物、器物。**
   - 例：乌鸦；收音机；理纱的信号灯；卡西法（会说话，但用火的尺度看世界）。
   - 原理：媒介本身就是笑点，它的"回答"总在错误的时间、用错误的方式到来。
   - 情境类型：一只总在场的乌鸦；一件在不该响的时候响的机器（收音机、村里的有线广播，看年代设定）；さぢ的铃在不该响的时候响；背负子的吱呀声。注意宪章的规则"神秘的声音必须有看得见的声源"。
3. **自大与现实的落差。**
   - 例：v0.1 的"本座"；赤玉先生；ジコ坊说完格言自己拆台。
   - 原理：架子越大，跌得越响；跌的时候还在端架子。
   - 情境类型：小鹊的职业骄傲（背夫的手艺、三十年没误过一单）撞上背不动、走不过去；さぢ"住哪家哪家兴旺"，唯独对小鹊不灵（已批准的笑料，第三版还没用上）。
4. **小气，加过分精确的单位。**
   - 例：一枚瓶盖都没供过；阿清点名要越后的竹叶糖；"キモい"收了没有。
   - 原理：用一个小得可笑的尺度去量大事，人格就出来了。
   - 情境类型：小鹊的账本，单位越记越荒唐（半颗团子）；在本该动感情的时候，她认真地处理"货"。
5. **冷面接梗（ノリ）。**
   - 例：吉吉"那呼吸呢？"琪琪"尽量别喘。"
   - 原理：不纠正荒谬，反而认真地把荒谬接下去。
   - 情境类型：さぢ对"家"（背负子）提一个荒谬的要求，小鹊按运货的规矩一本正经地报价。
6. **不打自招的否认。**
   - 例：v0.1 的"是老鼠""是风"。
   - 原理：没人问就否认，等于承认；跨物件重复成天丼。
   - 情境类型：供品少了一样，没人问，她先说"是风"。
7. **最后半句落地。**
   - 例：阿清"方向就不对"；v0.1"第一号也是唯一一号。不许骄傲。"；ジコ坊"这是师父说的"。
   - 原理：落地的半句是一个新的具体事实，不是总结。
   - 情境类型：任何一段正经的交代，末尾补一个拆台的小事实。
8. **天丼与三段：重复，升级，第三次翻。**
   - 例：《時そば》的模仿者失败；狸报菜名最后报出"鸡"；"好巧啊"一次次重复。
   - 原理：前两次建立规律，第三次打破。
   - 情境类型：小鹊数数被打断，从头数。第一次被さぢ打断，第二次被铃，第三次被一件真要紧的事，这一次她不再从头数。
9. **天真的听者，局外人看人话。**
   - 例：狸子不懂"狸汤"；狸议论"狸老爹"；v0.1 管火车叫"铁的蛇"。
   - 原理：威胁和惯用语都要靠对方懂；对方不懂，话就落空了，也就照出了人话本身的荒唐。
   - 情境类型：さぢ一百多年的庄屋规矩碰上新东西；小鹊给三十年里出现的新东西起老名字；小妖把人类的客套话当真。
10. **安排好的"偶然"。**
    - 例：《夜は短し》的偶遇和"好巧啊"。
    - 原理：观众知道，她不知道。
    - 情境类型：婆婆和屋里那个小的合伙，让小鹊"碰巧"路过鼓台。
11. **大事说小事，小事说大词。**
    - 例："活得久了什么都能经历"说的是菠萝；苏菲"老了的好处是不再吃惊"。第三版的「门闩我昨天才修好的……」也属于这一类，而且写得好。
    - 原理：分量放错了地方，人反而显得真。
    - 情境类型：灾后的第一句话说一件小事；小事上来一句"活了这把岁数"。
12. **语域突变。**
    - 例：瀧的身体里是三叶，她找不到该用哪个自称，わたし、わたくし、僕、俺挨个试了一遍（[映画スクエア](https://eiga-square.jp/title/kimi_no_na_ha/quotes/5)，转述）。
    - 原理：说话方式一错位，人就露出来了。
    - 情境类型：さぢ怕极了会冒出百年前庄屋的老派礼数（knowledge/23 §6.2 的症状初稿，待批准；第三版没用上）。被梁压着，正是"怕极了"。

### 4.4 节奏的几条硬规矩

- **停顿写进剧本。** 写成"停两拍""乌鸦不动"。停顿是一句台词。
- **铺垫要真。** 名乗り必须真庄严，诉苦必须真是诉苦。铺垫一假，包袱就不响。
- **一个来回只放一个笑点。** 不要一句里又双关又夸张又吐槽。
- **不解释笑点，不让旁人评论笑点。** 不写"你好好笑"，也不写旁白。
- **同一个机制一场只用一次。** 跨场重复（天丼）要变奏、升级，第三次要翻。
- **笑点从人物的欲望里出来。** 先问：她此刻想要什么？现实怎么拒绝了她？她怎么嘴硬？
- **最好笑的东西，和这场最难过的东西连着。** v0.1 的收音机就是这样。

## 5. 对 script-03 的逐处诊断

按场次。只给方向；示意句是本文自拟，不是要替主管重写整场。总体判断：第三版的大部分短句是有对象、有处境的口语，比第二版好得多。剩下的 AI 味集中在四处：婆婆的请求和信息密度；三四句说给玩家听的交代；两三句"造出来"的笑话和煽情；笑点机制单一，主角几乎不出丑。

### 第 1 场 九十九折

- 行商「哟，笠姑娘，又给庄屋送灯啊。」：明知故问是正常的寒暄（"又去送灯啊？"），可以留；但"哟"和婆婆的第一个字重了，两个人一个声音。换掉这个叹词。

- 行商「卖得差不多了，下山赶盆踊去。上头起风了，灯笼当心点。」：一句三件事。留一件，或者拆成两个来回。

### 第 2 场 道祖神

- 小鹊（对戴笠的那尊）「您的团子，我拿桃换了啊。婆婆说今早刚摘的，可甜了。」：这是全稿最接近 v0.1 的地方，小心眼、恶作剧、对不会回嘴的对象说话，但只做了一半。缺两样：一个停顿（石像当然不回答），和她在停顿之后补的那半句（再讨一点便宜、替自己找个理由，或者向旁边那尊不戴笠的也解释一下）。小鹊"一本正经地使坏"，就该在这里。

### 第 4 场 遠囃子

- 她哼半句，远处的笛子学了一遍。现在只用来制造诡异。这是现成的"不会说话的搭档"，像 v0.1 的收音机：可以在后面的场次里变成天丼，比如她故意哼错一个音，笛子也跟着错。注意遠囃子的来源在设定里另有安排，玩法上要先和主管确认能不能这么用。

## 6. 中文本地化：人物是日本人，台词是中文

### 6.1 两种失败

- **译制腔**：照搬日语的句法和语气，"话题＋逗号＋短句"、句句加"呢""哦"、主语代词一个不落。第二版被否的「今年的囃子，近」就在这一头。
- **浓妆**：把口语写成书面美文，四字格、成语、对仗。藤井省三批评林少华译村上春树"浓妆艳抹"，是用"文语体、书面语体"去译"口语体"；文雪的博士论文发现文学译本里译者自己的文风常常压过角色的说话方式，还专门分析了中文译本里的四字格。AI 写的叙述和格言容易落在这一头。

目标：**像好的中文口语，说话的人是日本山村里的人。** 两头都躲。

### 6.2 役割语：日中两边都别用

- 日语的〈老人語〉（わし、〜じゃ、〜ておる）是虚构的，首都圈的老人基本不这么说（金水敏）。本文读到的几位写得好的老人，说的都是地方口语：龙猫的奶奶的话像东北、北关东一带的乡下口音（片里没有设定是哪里），一叶说带方言的「〜とる」「〜なあ」，山形的老太太自称「オレ」。《平成狸合战》的老狸说「〜じゃ」，那是有意的戏剧腔：它们本来就是传说里的老狸。
- 中文对应的役割语："老身""老朽""老夫""老婆子我""咱家""孩子啊"（作为固定开头）。这些一用，人物就成了戏台上的老旦。
- 例外：人物自己在"演"的时候。v0.1 的"本座""吾乃……是也"好笑，正因为那是一个寒酸小神在摆谱。用役割语，就要让人看见她在演。

### 6.3 方言：撒几粒盐

- 三浦しをん的办法：大体写成标准语，留几个词，再告诉读者"他们其实一直说方言"。
- 文雪指出方言是中文役割语的重要资源。正因为这样才要小心：中文方言一用就把人物搬到了中国某个省。"嘎哈""要得""侬"一出口，人物就成了东北人、四川人、上海人。
- 建议：选一小组地域色不强的乡土词，固定给几个人物用。例如：晓得、日头、晌午、灶屋、不碍事、作孽、可不是、这孩子、嗐。具体词表由主管定，定了就进人设。
- 日本民俗词：能带出这个世界的保留（盆踊、送火、座敷童子）；日文汉字不进台词（第三版已经把"峠上""櫓"改成"山口""鼓台"，做得对）。

### 6.4 日语句尾的语气怎么过到中文

下表是本文的分析，不是出自某个研究。原则：**日语靠句尾助词表达的立场，中文要换成中文自己的语气词、句式和词序**，不是每句加一个"呢""哦"。

| 日语 | 功能 | 中文里常见的做法 | 注意 |
|---|---|---|---|
| 〜ね／ねえ | 求同、确认、拉近 | 吧、啊、是不是、对吧、"你说是不是" | 别用"呢"顶替 |
| 〜よ | 告知、提醒、坚持 | 啊、呀、哟、"我跟你说" | "哦"在中文里偏卖萌、偏网络腔，老人不用 |
| 〜かい | 老人、男人的软疑问 | 反问句（"你还怕我赖你那几个钱？"）、吗 | |
| 〜なあ | 感叹、自言自语 | 哟、啊、"……呀" | |
| 〜とくれ | 老派的请求 | "给我……""……去"，加"吧"软化 | |
| まあ | 缓冲、让步 | 也就是、嗐、行吧、罢了 | |
| ほら | 引起注意、拉人站队 | 你看、瞧 | |
| おや | 轻微的意外 | 哟、咦 | 婆婆、一叶型的老人用 |
| 话说一半（言いさし） | 请求、拒绝不说满 | "那个……""你说这……"、省略号收在半句 | 中文同样成立 |

### 6.5 称呼和自称

| 日语 | 中文 |
|---|---|
| ばあちゃん（对小辈自称） | "婆婆""奶奶"："婆婆还能骗你？" |
| あんた（老人对小辈） | "你"；急了"你这孩子" |
| 昵称（みっちゃん） | 固定一个，只有她叫：小X、阿X |
| 〜さん | 一般不翻；用名字或身份（行商叫她"笠姑娘"就很好） |
| おれ／おら（乡下老太太） | "我"；"俺"北方色重，慎用 |
| わし（役割语） | 不翻成"老夫"，除非人物在演 |

### 6.6 笑点怎么过语言关

- **机制能过，双关不能过。** 节奏、反差、天丼、最后半句落地，换成中文照样成立；「タヌキ寝入り」「玉砕」这类双关不行，"座敷饼"这种硬造的也不行。要么换成中文自己的双关（v0.1 的"灯笼本来就该稳重一点"，借"稳重"一词同时说重量和性格，成立），要么放弃双关，用机制。
- **中文有现成的资源。** 相声的"铺平垫稳""三番四抖"，就是漫才的铺垫和三段オチ；捧哏顺着逗哏往下说，就是ノリツッコミ。歇后语、俏皮话地域色和时代感都重，慎用。
- **自称变换的笑话要重造。** 日语的わたし、わたくし、僕、俺，中文只有一个"我"；中文能玩的是"我""本座""在下""人家"之间的切换。

## 7. 规则清单（可以直接补进 `dialogue-writing` 技能）

1. **长辈的请求至少绕一道弯**：诉苦后留半句、讲先例、拉第三方、拿吃的、当作已经定了、或者把好意包成别的事。干脆的祈使句只留给小事、急事，和不会拒绝的自家小辈。
2. **每段对话允许一两句"没用的话"**（寒暄、抱怨天热和膝盖、说吃的），它们承担关系，不承担信息。一场里的信息点不超过三四个，其余交给动作和东西。
3. **看法要有缓冲，拒绝要有延迟。** 长辈下判断前后有软化和求同（也就是、我看哪、你说是不是）；拒绝先拖、先让、说一半。
4. **格言只许出现在两种地方**：被说的人自己拆台（"这是我师父说的"），或者作为一个荒谬处境里的反应。不许当一场的总结。
5. **写笑点之前，先问谁在不合作。** ボケ让对话出错，ツッコミ把它拉回来。没有人不合作，就没有笑点。
6. **不会说话的搭档要写进节拍。** 动物、器物、雕像、空位的"回答"（沉默、噪音、动作）写成一拍，标明停顿。
7. **主角也要出丑。** 每段戏里，至少有一处她的体面被现实拆穿，或者她一本正经地使了个小坏。
8. **同一个笑点机制，一场只用一次**；跨场重复要变奏、升级，第三次要翻。
9. **最后半句落在一个新的具体事实上**，不落在总结上。
10. **怪事当家常说**：本地人对本地的怪事不惊、不讲解，用开会、搬家、闹脾气这类家常的说法。
11. **不用役割语**（老身、老夫、老婆子我……），除非人物在演而且观众看得出她在演。方言词只撒几粒，用词不用腔，不用能定位到中国某个省的方言。
12. **双关要么是中文自己的，要么不用。** 不造只有懂日语才拆得开的词。
13. **说话的人有年纪、有身体。** 年纪和身体（膝盖、牙、耳朵、手上的活）至少在台词里出现一次。
14. **加一个测试：长辈测试。** 读出声，想象你认识的某个乡下老太太。她这辈子会不会这么说？不会，就重写。
