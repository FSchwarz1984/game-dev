# 3/4 俯视的透视规则（R-1 的根本修法）

> **2026-10-14 用户否决（G5R-4）：第 1–3 节"平台加崖、台阶嵌进崖、路贴在平台上"作为唯一高差语言作废。**用户原话见 decision-log G5R-4："我不喜欢这种，要么是悬崖，要么是阶梯的方式……违背人的生活感知经验"。新的地形路线以美术样章为准（可以融合 3D 技术，不能有方块感）。第 0 节的投影说明和第 4–5 节只作 2D 管线的历史参考。

来源：用户对 JS 版第一段的批评（R-1："台阶做的非常突兀，和画面的透视根本就不一样；道路的透视和画面也不一样，整个画面内容透视非常混乱"），以及 Zelda 式 / 风来之国式 3/4 俯视的通行画法。日期 2026-10-14。这份规则是所有地形、道路、台阶、崖面、建筑素材的共同前提；任何素材违反其中一条就不能进游戏。

## 0. 投影

- 我们用的是**斜投影（oblique）**：屏幕 x = 世界 x；屏幕 y = 世界 z（南北，往南为下）− 高度 y。三个方向都是 1 米 = 20 原生像素。
- 结果：**水平面**（地面、路、台阶的踏面、墙顶、屋顶的平面部分）按俯视的样子画，形状不压缩；**朝南的竖直面**（崖面、台阶的立面、墙和房子的正面）按正视画，1 米高 = 20 像素；**朝东、朝西的竖直面**在严格投影里是一条线，画的时候只给 1–3 像素的"侧边"示意厚度；**朝北的竖直面**看不见。
- 光从左上来：影子落在物体的右下方，长度随时间连续变化。
- **受光与投影分开处理（主管定，2026-10-14）。** 严格按物理算，"影子朝右下"要求太阳在西北，这时朝南的崖面全在阴影里（地形第一版的黑带）；把太阳挪到西南偏西，崖面亮了，影子却朝右上（knowledge/17 §4 记录了这个取舍）。2D 像素游戏的通行做法是不追求物理一致：
  - **投影**（地平线贴图、树和物体的影子）按西北的太阳算，一律落在右下方；崖脚因此有一条随太阳高度变长变短的影带，正好把崖"压"在地上。
  - **表面受光**按屏幕空间的约定：法线贴图里，水平面朝向观众并略向上偏，朝南的竖直面朝向观众并略向下偏，于是"左上方、略在前面"的主光照下：顶面最亮，朝南的面是中间调、有清楚的岩层，朝东的侧边最暗，朝西的侧边受光。
  - 两者都随时间连续变化，不跳变（R-7）。这不是要用户拍板的事：用户要的是"崖面看得清、影子方向一致"，两条都已经在规则里。

## 1. 地形：平台加崖，不要连续的斜坡

- 世界由**一层层平的平台**组成，高度取 0.5 米的整数倍；平台之间是**竖直的崖面**。这是 3/4 俯视能画清楚的唯一地形语言。
- 连续的斜坡在斜投影里会变形（往北上升的坡会被压扁，往南下降的坡会被拉长），画出来像透视错了。**只允许很缓的坡**（坡度不大于 1:3），而且要画成"有坡的平面"：用明暗渐变和边线表现，不要用崖面。
- **崖面只朝南（朝镜头）显示**，高度 = 两层平台的高差 × 20 像素。崖的东西两端收成窄的侧边，北边只是平台的上缘。
- 崖的轮廓必须是有机的：边缘线有凹凸，崖面有岩层、裂缝、根和垂下来的草，底部有碎石堆和阴影；崖顶边缘有草皮的翻边。**绝不出现 20 像素一格的方块台阶感。**

## 2. 台阶

- 台阶只朝南北方向走（玩家从下往上看着它爬上去）。每一级 = 一条**立面**（朝南的竖直面，高 h × 20 像素）+ 一条**踏面**（水平面，深 d × 20 像素）。整段台阶在屏幕上的高度 = 总高差 × 20 + 总水平长度 × 20。
- 台阶必须**嵌进崖里**：台阶的底端落在下层平台上，顶端接在上层平台的边缘，两侧是崖面的切口和侧壁（侧壁的南面看得见）。台阶两边的崖面高度和台阶的总高差一致。JS 版的错误就是台阶像一张贴在坡上的长方形，高度和旁边的崖对不上。
- 东西方向的上下：用折返的南北台阶，或者沿崖面的窄栈道（看得见栈道的正面），不画"横着走的台阶"。
- 石阶要有手作感：石板大小不一、边缘缺角、苔从缝里长出来、两侧有边石和草。

## 3. 道路

- 路**贴在平台上**，是地面材质的变化（土、碎石、石板），宽度在各个方向上一样（往北的路和往东的路一样宽）。
- 路**不爬崖**：换层的地方，路接上台阶或缓坡。之字形山路 = 一层层平台上的路段 + 每一折处的台阶或缓坡。
- 路的边缘是有机的：车辙、被踩秃的边、路边的草被压倒，转弯处外侧有碎石。路不是贴在地上的色带。

## 4. 建筑与大物件

- 建筑：看得见屋顶（俯视）和正面（正视），东西侧墙只给很窄的侧边；Q 版比例（大楠例外）。
- 树：树干正视，树冠是从斜上方看的团块；树根铺在地面上（俯视），和树干连成一体；树冠和树干之间不能有断开的缝，也不能露出贴图的直边。
- 所有高物件以底边的 y 排序（Y-sort）；挡住角色时淡出或挖透视孔。

## 5. 水

- 水面是水平面；岸是低矮的崖或缓坡；瀑布是朝南的竖直面；桥是水平面加朝南的桥身侧面。

## 6. 检查清单（每个场景交付前过一遍）

- [ ] 每一处高差都能说出"上层多高、下层多高、崖面多高"，崖面像素高度对得上。
- [ ] 每一段台阶的两端都落在平台上，两侧有切口和侧壁。
- [ ] 每一条路都在平台上，换层处接台阶或缓坡。
- [ ] 没有一处看得出 20 像素的网格。
- [ ] 所有影子都朝右下，长度和当前时间一致，没有跳变。
