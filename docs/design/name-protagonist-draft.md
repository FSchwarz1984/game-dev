# 主角的名（提案草案）

> 状态：**已批准方案 A**（G5R2-5，2026-10-15）。原为草案，回应 G5R-1："主角的名字最好稍微调整一下，因为毕竟叫小鼓但却是个斗笠的付丧神给人感觉难免会有歧义"。
>
> 约束（已批准，G1R4-1）：
> - 名用平假名，带一个旧式或不常见的假名记号，三人共用这种"怪"的记号（ゞ、ぢ、を）；
> - 华文要一眼像女孩子的名字。
> - 姓「百々」是真身"百関"的线索：老背夫只听清她喃喃说了"もも……"。

## 判断

- 名要同时承担两层：**表面**一眼和"笠"相连，消除歧义；**底下**像「百々」一样连着真身，即两岸之间的关。旧名「つゞみ」的长处是底层（鼓的两面、成双的叠字），短处是表面和笠无关。
- **姓「百々」建议保留。**它是全作最重要的一条明线索，和笠无关，也没有歧义。

## 推荐 A 的理由与要改的地方

- 表面上，"かさ"一出口就是笠，歧义没了；底下，鹊桥连着两岸、连着盂兰盆、连着她的真身，和「百々」一样是摆在明处的线索，要到真身揭晓时才会被读懂。
- 要改的地方：
  - characters.md 的"名"一段；
  - 旧名"鼓"带出来的设定（"小鼓是沙漏形的……敲这一面，另一面也在响"）改由鹊桥承担，"两岸、中间一道关"的意思不变；
  - 「音」的效果里"她的身体像鼓一样共鸣，名字的由来"一句删去，改成"笠沿的菅草像风铃一样响"。
- 什么时候选别的：想要最短、最直接的笠名，选 B；想把"重"放进名字里，又不在乎旧假名规则，选 C。

## 请你决定

名用 A / B / C，或者给方向。姓「百々」是否保留。
