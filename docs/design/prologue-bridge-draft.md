# 序章：天门的聚光和町的爆点之间的衔接（G5R3-61）

> 状态：**草案**（待审批）。实施排在队列第 9 项，和 G5R3-50（信号塔镜头的枝叶）、中景 D（G5R3-62）一起做。
>
> 用户原话（G5R3-61）："我注意到所有的燈火聚集在天岸那邊之後，最後原爆點爆開的那邊卻是在町那邊，就是這兩個畫面之間缺我覺得缺少一個銜接……能量集中的地方是在天岸的那個山一樣的尖端，但是能量爆發的地方卻是在地上，而且離那個尖端是有像右側的些許方位上的偏移……你可以策劃一個看上去很不錯的很好的一個銜接的方案給我看一下，同時我也想先保留一下現在的這麼一個成果，以便做對比與備份。"
>
> 依据：story.md（两岸共用一份性质，像沙漏；冻住三十年的潮冲破「隔」，平原的灯升向天岸，"沿途万物的性质被粗暴地抽走"，没有恶人）；yi-v2-draft.md（遠化的东西颜色被抽走，性质还回去颜色就回来）；decision-log G5R3-22、G5R3-26、G5R3-50、G5R3-62；knowledge/14 第 7 节（升灯的画法、遠化的画法）。
>
> 现在的序章原样保留（`Vista.bridge = "none"`，默认），作对比和备份；衔接做成可以切换的另一版。中景 D 会在第 9 项里一起做，两版都有。

## 0. 结论

推荐 **A「抽色」**：塔灭、回到平原以后，天门先"吸一口气"，町上的颜色变成一粒粒的光，从整片町笔直往上浮，再各自加速、沿自己的弯路弯向天门，中段散开、到门口才收拢——是前面升灯那一幕的"最后一口气"，同一种画法，只是从町一处起来、更急；颜色离开的地方变成遠化的银灰；然后町心一闪白，潮从那里扩开（就是现在的远之浪），最后几粒光进门时天门再亮一下。整段多 3.4 秒。它把"能量聚在天门、爆发在町"之间缺的那一段补上了，方向和世界观一致（性质从地上流向天岸），还把"遠化 = 颜色被抽走"直接演了出来。

## 1. 问题

序章里所有的灯都升进天岸的尖端（天门，画面上方偏左），塔灭、切回平原以后，遠化的潮却从町（地上，画面中部偏右）爆开。两处之间没有任何东西把它们连起来：看的人知道能量聚在上面，却看到它在下面另一个地方炸开。

**位置**（1920×1080 窗口实测。序章远景在 1080p 下画的是它自己的 480×270 画布，每个远景像素 4×4 个屏幕像素，knowledge/14 7.9 ⑤；括号里是换算到 640×360 舞台像素的位置，×4/3）：

| 东西 | 远景像素（480×270） | 舞台像素（640×360） |
|---|---|---|
| 天门（漏斗口） | (216, 39) | (288, 52) |
| 町（潮的第一帧） | (283, 158) | (377, 211) |
| 天岸倒挂五重塔的相轮尖 | (303, 100) | (404, 133) |
| 她（脚） | (298, 229) | (397, 305) |

町在天门右边 67、下面 119 个远景像素。这一刻构图已经回到正常（地平线 47%），町和光流要走的路上没有树冠和近景枝挡着（近景枝在升镜结束时已经出了画面，树冠在她脚下）。

**来历**：G5R3-22 以前，潮从天门正下方的地面扩开（`4000176` 的 `south.js`：Zc = 26 单位 ≈ 4.7 km，横向正对天门），和聚光的尖端上下对齐。G5R3-22 把原爆点挪到町（户数最多的村，离树冠 2.2 km），为的是和 3D 眺望的遠化同一个中心（"原爆点和分圈和 3D 眺望是同一套"）；这个错位是那次挪动带进来的。

## 2. 选项

分镜在 `bridge_out/`（见第 8 节）。A、C 是游戏里实际渲染的帧；D 是用试烘焙的数据实际渲染的帧（数据没有入库）；A′、B 是在现版的帧上画的示意，没有做样稿。所有时刻都从"塔灭、切回平原"那一帧算起。

### A「抽色」（推荐）

| 时刻 | 画面 |
|---|---|
| 0–0.3 s | 切回平原，静一下：天门只剩微光，地上的灯早已升走（和现版一样） |
| 0.3–0.9 s | 天门"吸一口气"：一圈十二个淡淡的光点往门口收拢、转进去，门口的外圈光往里收，核心变亮 |
| 0.45 s 起 | 町上升起第一粒、第二粒光，很慢，笔直地往上浮 |
| 0.5–3.6 s | 越升越多、越来越急（有几阵稍密）。每粒光带着它离开的那块地的颜色（照材质原色，不另染：茅草屋顶的稻草黄、瓦的灰白、白墙的米色、屋敷林和稻田的淡绿），先笔直地升，再各自加速、沿自己的弯路弯向天门：有的往左边散得远，有的贴着走，中段散成一团，到天门口才收拢，从下方进门；过了半路渐变成天岸的淡翡翠色（和升灯同一个规则）。颜色离开的地方变成遠化的银灰（和潮过之后的银灰同一组颜色），从町心往外扩；町旁篝火的余烬随之熄灭 |
| 约 2.65 s | 头一批光进门，天门随之一亮一亮 |
| 3.4 s | 町心一闪白，潮从那里扩开（之后就是现版的远之浪，速度、画法都不变） |
| 3.4–5.5 s | 大部分光在这两秒里进门（爆点之前进门的是头 18 粒），在门口收拢；最后一粒进门时天门再亮一下，然后慢慢呼出那口气 |

- **多出的时间**：3.4 秒（65.6 → 69.0 秒）。之后她站起、喊、白潮涌上树冠，都和现版一样，只是晚 3.4 秒。
- **逻辑**：方向和升灯一致（都是从地上往天岸去），和 story.md 的"沿途万物的性质被粗暴地抽走"对上；町为什么是原爆点也有了交代：那里的东西最多，被抽空的地方先爆开。
- **视觉语言**：和前面升灯那一幕（`8196ebf` 的画法）是同一种：每粒光一条自己的三次贝塞尔曲线，出发时刻、速度（±15%）、升多高再弯（12–30 像素）、往哪边弯、弯多远都各不相同，越接近天门越收拢；一像素的光核（三分之一带一圈两像素的微光），沿自己曲线的一到两节短尾巴，不画把两粒光连起来的线，没有实心的柱子；泛光只给光源（天门、町心的爆点、光核）；过半变淡翡翠色；遠化的银灰。和升灯不同的只有两点：都从町一处起来；更急（1.6–2.7 秒走完，升灯是 7–10 秒）。光粒共 150 粒；最密那一帧（爆点后 0.37 秒）在 1 倍下是一团散开的光点，读不成线（`A_densest_1x_t58.47.png`）。
- **和倒挂塔不打架**：在倒挂塔那几行（相轮尖到塔身），光粒离塔至少 22 个远景像素；最近的地方是相轮尖左下方 17 像素，那里的光粒正往左上走、离塔而去（长曝光图）。光群的鼓肚子朝左，就是为了离塔远一些。
- **改过一版**：第一版把光粒拧成三股缠绕的光流，内部看过，1 倍下三股读不出来，读成一根又直又细的绳子、一条光束，底部像两条腿的帐篷，和前面升灯的语言也不统一，已经改成现在这样。

### A′ 经由相轮（评估了，不推荐）

光流先从町笔直升进倒挂五重塔的相轮（九轮一圈圈亮起），再沿天岸的底面流向天门。相轮尖几乎正好在町的上方（右 20 像素），画面上确实很巧。

不推荐的理由：①逻辑变复杂：所有的灯都直接进天门，只有町要绕道进塔，塔在故事里就多了一个"导管"的身份，这是没批准过的新设定；②路线是两折，第二折沿着天岸底面走，正好穿过天岸的城镇灯火，读不清；③相轮在町上方是 G5R3-22 挪爆点时的巧合，不是设计，以后中景、构图一动就可能不再对齐。

### B「落光」（只做示意）

聚在天门的光落下一滴或一道，沿弧线落到町，炸开。最符合"能量集中—爆发"的直觉。

不推荐：方向和世界观相反。性质是从地上流向天岸的；光从天门落下来打在町上，读起来就是天岸在攻击地上，和"没有恶人"、"地岸的灾难是天岸的复活"冲突。要选它，得先改剧情的说法。

### C「同时」（最小改动）

切回平原以后静 0.8 秒；然后天门猛地一亮（一团淡翡翠色的白光，半秒内退去），同一帧町心一闪白，潮扩开。多 0.8 秒（65.6 → 66.4 秒）。

最含蓄，现版的节奏几乎不动。代价：位置的错开还在，只靠"同时"连起来；眼睛一次只能看一处，天门和町隔着 119 像素，大多数人会看到一个、余光扫到另一个，因果读不读得出来不确定。地上的灯在塔之前已经全升走了，所以"町的灯同时全灭"这一条没有东西可灭，只剩余烬随潮熄灭。

### D「挪回」（试渲染）

原爆点挪回天门正下方的地面（G5R3-22 以前的位置），不加任何东西，上下对齐。

不推荐：①町不再是原爆点，3D 眺望的遠化中心要跟着挪，G5R3-22 里"町一带最重"、两边同一套分圈都要改，用户已经看过的眺望也要变；②新的中心落在空的平原上（3D 数据里离它最近的村只有 10 户，531 米外），失去"东西最多的地方先被抽空"的道理；③画面上的对齐只解决"在哪里"，没有解决"怎么过去的"：聚光和爆炸仍然是两个镜头里的两件事；④试渲染里看得出，4.7 公里外的潮先是地平线附近的一条细线（离得远、被压扁），爆开的感觉比现在在町弱很多。用户在 G5R3-22 说"那個動畫是在平原的差不多中心位置像一個原爆點一樣爆開"，指的就是这一版的位置。

### 不加

保留现版。用户自己说过"只要不細細去想也不是什麼大問題"，加东西也可能更坏。如果看了 A 和 C 的分镜觉得都不如现版，就不加。

## 3. 推荐与理由

推荐 **A**：

1. 补上的正是缺的那一段："从町到天门"有一条看得见、连续的路，因果不用观众自己推。
2. 方向和世界观一致；B 反了，C 和 D 没有路。
3. 把遠化"颜色被抽走"的规则直接演出来，和 G5R3-22 的银灰、yi-v2 里"性质还回去颜色就回来"是同一条视觉规则，后面玩法里玩家会再见到。
4. 不动构图、天岸、云、灯的样子，不动町的位置和 3D 眺望；用的都是已有的视觉语言。

## 4. 关键变量

- **看不看得出"从这里到那里"**：A 有路；C 只有同时；D 去掉了错位但没有过程；B 有路但方向反。
- **方向**：性质从地上流向天岸（story.md），这是不能动的世界观。
- **节奏**：现版的好在于克制。A 多 3.4 秒，C 多 0.8 秒。
- **和已批准决定的关系**：G5R3-22（町为原爆点、序章和眺望同一套）只有 D 要动。

## 5. 代价与风险（A）

- 多 3.4 秒，爆炸来得晚一些；塔灭之后那一下安静被一个动作代替了（开头仍留了 0.3 秒的静）。可以压到约 +2.6 秒（拿掉开头的静和慢起），代价是起势不够、更像特效。
- 现在的风险反过来：光群散开以后，"从町到天门"这条路是一团光点而不是一条线，单看一帧时连接感比第一版弱，要靠动起来（光点一直往门里走、门一亮一亮）读出来；长曝光图里路很清楚，但用户看的是动起来的样子。我判断动起来读得出，不确定。
- 光粒的颜色照实：町心一带（光粒出发的 333 个地面像素）是茅草屋顶 35%、瓦 33%、白墙 10%、屋敷林和稻田约 15%、路和田埂其余，所以大多是稻草黄、灰白、米色，约六分之一是淡绿；用的是每种材质本来的颜色（烘焙导出的材质原色，只提亮度、不提饱和度，没有另编调色板），上半段统一成淡翡翠色。1 倍下颜色不鲜明，这是照实的结果。
- 天门的"吸气"：十二个光点往门口收拢、核心变亮，1 倍下看得出，但单看一帧时那一圈点有点像瞄准圈，动起来才是"收进去"。
- 町心在爆开之前就开始变成银灰，所以潮头最初那一圈白是在已经变银灰的地上走过的。
- 声音要新做几条（第 6 节）。

## 6. 声音需求（声音整体在重做，这里只写需求）

- **A**：①天门吸气：0.6 秒的反向渐强，像倒放的磬或玻璃的摩擦声，从上方来；②抽色：很多细小的、玻璃质的颗粒声，音高随光流往上走，一阵一阵地加快（跟着五阵光），声源在町、往天门方向移；③爆点：一声闷的、低的"咚"，不是爆炸；接着环境声一下子变空（现版远之浪的声音照旧）；④最后一粒进门：天门那里一声很轻的高音。
- **C**：一记同时的重击：深的钟或拍子木，天门一亮和町心一闪在同一声里；之后接远之浪。
- **B、D**：B 要一声下落的呼啸和落地的闷响；D 不需要新声音。

## 9. 实现现状（内部样稿，没有交付）

- `Vista.bridge`：`"none"`（默认，现版）、`"drain"`（A）、`"flash"`（C）；命令行 `--vista-bridge=NAME` 可覆盖（内部对照用）。A 和 C 的一切都由 `state.drain`（抽色开始后几秒）和 `state.flare`（爆开后几秒）决定，只有这两个变体会设它们；所以 `"none"` 除了信号塔镜头的修改（G5R3-50），每一帧都和改动前一样。
- 新文件：`godot/vista/south_drain.gd`（光粒的计划：起点、出发时刻、速度、各自的曲线、颜色；天门的吸气和闪光；地面银灰的半径）、`godot/vista/shaders/drain.gdshader`（光粒、天门吸气的光点、爆点在 GPU 上的运动）。改动：`vista.gd`（时间线）、`south.gd`（接线）、`ground.gdshader`（爆开之前町一带先变银灰）、`shorelights.gdshader`（天门吸气）、`lamps.gdshader`（余烬随抽色熄灭）。烘焙多导出一张"每个地面编号的材质原色"（`south.json` 的 `groundAlbedo`），所有图像逐字节不变。
