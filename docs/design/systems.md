# 系统（G1/G2 草案）

> 状态：**草案，待审批**（2026-10-14）。已批准的前提：「移」的取/予/放；五性重・熱・光・音・生；高阶性质形・声・名・魂；搬运建设必须可视可感（D4）；杀或平息由玩家决定（D11）；作物更丰富 + 城镇建设（D12）；操作方案 A（D13）。依据：`docs/knowledge/01`、`04`。

总原则：**所有系统都经过「移」。** 种田就是搬运性质；建设需要的材料是世界里的实物；小伙伴是有魂的器物；战斗是性质的失衡与再平衡。

## 1. 「移」与五性

### 1.1 三条定律（写在化学表之前）

1. **只搬运，不创造。** 性质从来源移到目标，来源看得见地失去，目标看得见地获得。
2. **物不自变。** 物体之间不经过转移就不会互相改变；环境（太阳、火、水流、风）是持续的来源和汇。
3. **A+B=AB。** 得到性质的东西外观不变，只多出这种性质的标记；永远不会变成另一种东西。

### 1.2 五性（新增「生」）

| 性质 | 来源 | 给了东西会怎样 | 她带着很多时 | 她把自己的给出去时 | 放 |
|---|---|---|---|---|---|
| 重 | 岩石、石像、湿木 | 下沉、压住机关、砸碎树桩 | 走得稳、不怕风；压断朽桥，在水里下沉 | 变轻：被风送过断崖、站上浮叶、走过朽桥 | 震地，推开周围 |
| 熱 | 太阳、火、炭窑、温泉 | 冰化水、水沸成雾、枯草起火、作物抗霜 | 融雪开路、呼白气；碰到枯草就点着 | 变冷：脚下的水结冰，可以走过水面 | 火圈（风会带火） |
| 光 | 太阳、林间光束、萤火虫、灯笼 | 照亮洞穴、催作物、驱散暗处的小妖 | 身体发光，看得见夜路；招来夜行小妖 | 变暗：融进阴影 | 闪光，致盲周围 |
| 音 | 瀑布、风铃、蝉、钟 | 钟响、引开注意、震落高处的东西 | 脚步铃声震响，吓退野兽 | 无声：潜行；在瀑布边听见被盖住的声音 | 咆哮，击退并惊动周围 |
| **生** | 杂草、竹笋、动物、小妖 | 作物长一阶、种子发芽、藤蔓长成梯子或桥、伤口愈合、枯树复苏 | 脚印里开花，缓慢回复；招来草食动物和虫 | 变得虚弱，但小妖感觉不到她（像死了一样）：另一种潜行 | 草木疯长，缠住敌人，治疗周围的同伴 |

- 大楠的「生」极多，但被注连绳围着：神物不能取。这是"不能取"唯一的标记。
- 把小妖的「生」全部取走，就是杀死它（见第 5 节）。同一个动词可以杀生——这是有意的设计。

### 1.3 她的身体就是货箱

- 能带的性质份数有上限，随成长增加。带着什么，身体就变成什么样（上表第四、五列），直接改变走路、渡河、潜行和战斗。
- 背负子上的实物货堆（v0.1 保留下来的好东西）同时存在：重的货让她走慢、晃，取走货的重量可以背更多。
- **代价防一招通吃：** 带着重走得慢；带着光招小妖；带着热会点着脚下的枯草；带着生招来虫；带着音没法潜行。
- **实验安全：** 主线上的关键物体受保护（注连绳或剧情锁）；搬错了，可以在家里的神棚前把性质"归还"原处。

### 1.4 反馈（法术五步）

预览（目标描边 + 性质流的预告线）→ 施放（她的手势，0.1 秒内必有声音）→ 可见状态（来源变干瘪、目标变饱满、她的身体变化）→ 可预测的结果 → 回报。每种性质固定一种颜色、一个图标、一族声音；失败也要有反馈（"装满了""它已经没有热了""太远了"）。

## 2. 百鬼队：小伙伴系统（皮克敏 × 宝可梦 / 幻兽帕鲁）

### 2.1 小伙伴从哪里来

- **付丧（唤醒器物）**：废墟和山里散落着用了很久的旧器物。ツヅラ把一份**「魂」**给它，它就站起来，成为付丧神。魂来自神棚前的供品（人和妖的心意），所以供品系统直接喂养小伙伴系统。
- **平息的小妖**：被平息的小妖有机会留下来（见第 5 节）。
- 全部记在**百鬼帳**里：九十九格，外加一格空白（第一百格，见 `story.md`）。

### 2.2 新手区的种类（草案）

| 草鞋 | 付丧 | — | 跑得最快：送信、送小件 |
| 鉄瓶 | 付丧 | 熱 | 烧水、做饭、融冰 |

### 2.3 指挥（像皮克敏）

- **跟随**：小伙伴排成一列走在她身后——这就是一支小小的百鬼夜行，也是作品的标志画面。
- **派遣**：用同一个目标选取系统选中东西，按"派遣"：最合适的小伙伴跑过去搬、建、耕、打。搬运需要的力量等于物件的重量，人手不够时物件不动，头顶显示"还需要 3"。取走物件的重量，就能少派几个。
- **召回**：サチ摇铃。
- **路**：小伙伴沿着她踩出来的路走，路越熟走得越快（死亡搁浅的"踩出来的路"）；遇到远化区、断桥、深水会停下来等她解决。

### 2.4 据点里的岗位（像幻兽帕鲁）

给小伙伴分配岗位：厨房（鉄瓶）、田（鍬、唐傘、瓢箪）、木工场（鋸、金槌、臼）、仓库（籠）、照明（提灯、鬼火）。岗位上的工作同样肉眼可见：鉄瓶在灶上冒气，鍬在田里一下一下地刨。

### 2.5 成长（像宝可梦）

小伙伴有性格、喜好的供品、经验；用得多会长成新形态（例如提灯 → 大提灯，籠 → 大籠）。百鬼帳记录每一只的来历——每个器物都带着前主人的一个小故事。

## 3. 城镇建设（像勇者斗恶龙 创世小玩家 2）

### 3.1 材料是实物

- 木头、木板、石头、竹子、稻草、茅草、黏土、瓦都是世界里的实物。由她背、由小伙伴扛，运到工地旁的**资材堆**；资材堆看得见地变高。
- 没有"背包里的木材 ×99"。小件（种子、供品、食物）放在背负子上挂着的布袋里，有格数上限。

### 3.2 施工可视

- 在废墟或空地上放置**设计图**（半透明的建筑轮廓）。设计图来自废墟里找到的旧图纸、居民的请求，或自己组合。
- 七个阶段，每个阶段的材料都要实物运到：清地 → 础石 → 立柱 → **上梁**（上梁仪式，抛年糕）→ 墙 → 屋顶 → 装修。小伙伴肉眼可见地夯土、立柱、铺茅草。
- 1 米网格，90° 旋转，建筑按 Q 版比例；地基随梯台地形。

### 3.3 房间配方

四面围起来、放进特定家具，就成为有功能的房间：

| 房间 | 配方（例） | 作用 |
|---|---|---|
| 囲炉裏の間 | 囲炉裏 + 坐垫 + 围墙 | 聚会、取暖（熱） |
| 寝間 | 布团 + 行灯 | 休息、存光 |
| 台所 | 竈 + 水瓶 + 架子 | 做饭（鉄瓶的岗位） |
| 湯殿 | 引来的温泉 + 浴槽 | 回复、存热 |
| 神棚の間 | 神棚 + 供品台 | 供品 → 魂；归还性质 |
| 作業場 | 作业台 + 工具架 | 制材、做家具 |
| 茶屋 | 缘台 + 茶釜 + 招牌 | 接待过路的妖怪（委托与交易） |
| 蔵 | 门 + 架子 | 储存实物，存重 |

### 3.4 居民与热闹度

- 居民：小伙伴、平息后的小妖、第一章起的难民。
- **居民的需求本身就是性质**：冬天要热、夜里要光、病人要静（取走音）、新生要生。经营就是管理性质的流动。
- 房间与居民的满足度累积成**热闹度**，宿场升级，解锁新配方和新能力。
- 一栋成形的"家"会得到サチ的**家运**加成（收成、掉落、偶遇）。

## 4. 开荒与作物

### 4.1 开荒

巨石（取走重量再搬开或叫小伙伴抬走）、树桩（给它加重砸碎）、荒草（给热烧掉，注意风向，或让箒取走它的生）、乱石墙、坏掉的水渠。

### 4.2 作物：生长条件就是性质

每种作物需要光、热、水、生的不同组合，外加特殊条件。「移」让你干预这些条件，但所需的性质要从别处搬来。

| 作物 | 季节 | 特殊需要 | 「移」怎么帮 | 用途 |
|---|---|---|---|---|
| 胡瓜 | 夏 | 竹支架 | 给光 | 食物；**精霊馬**（马） |
| 茄子 | 夏 | 喜热 | 给热 | 食物；**精霊馬**（牛） |
| 西瓜 | 夏 | 热、水 | 给热；收获后取热冰镇 | 盂兰盆供品 |
| 鬼灯 | 盂兰盆 | 白天给的光会存起来，夜里发亮 | 给光 | 盂兰盆的引路灯 |
| 夕顔・瓢箪 | 夏夜 | 只在夜里开花 | 夜里给生 | 瓢箪 → 容器 → 付丧神 |
| 茗荷 | 夏末 | 喜阴、湿 | 种在大树下，或取光 | 调味 |
| 蕎麦 | 夏—秋 | 贫地也能长，长得快 | 给生 | 荞麦面 |

- 种田连回建设：稻草做茅草屋顶，麻做绳，柿渋防水；连回剧情：精霊馬和鬼灯是送り盆用的东西。

## 5. 杀，还是平息（像 Undertale）

- **平息（鎮め）**：取走它多余的那种性质，或补上它缺的。它平静下来，被偷走的性质归你；有机会留下来成为小伙伴。难，要读懂它。
- **讨伐（討つ）**：把它的「生」全部取走。它消散，留下材料和一阵它的性质。快，省事。
- **世界记得：**
  - 被杀的小妖不会再出现；百鬼帳上那一格被划掉。
  - 小伙伴们（它们也是妖）会害怕：士气下降，有的会在夜里悄悄离开。
  - シオン记得，并且会数。杀得多了，她不再对你微笑。
  - サチ：座敷童子会离开作恶的家。杀到一定程度，她会从背负子上下来（能否挽回待定）。
  - 遠囃子的旋律会变。
  - 远期：不杀、中立、"百鬼杀"三条路线有不同的台词和结局。
- 误杀一只不会毁掉什么，但一切都会被记下来。

## 6. 一天

黎明计划 → 白天出门搬运、探索、战斗 → 黄昏回据点种田、建设、分派岗位 → 夜里危险，但有只在夜里才有的东西（萤火虫是光源、夕顔开花、鬼灯发亮、夜行的回响）。每一段都为下一段制造需求。游戏里一天的长度待定（建议约 20 分钟）。

## 7. 操作（方案 A 已批准，补充小伙伴和镜头）

- **键盘**：WASD 移动，Shift 跑，Space 闪避，E 情境动作，**1–5 取**对应的性质，**Shift + 1–5 予**，L 放，F 派遣，R 召回，Tab 切换目标，[ ] 旋转镜头，H 问サチ（嗅运气）。
- **手机**：左侧浮动摇杆；右下大的情境键，五个性质键环绕它（点 = 取，上滑 = 予）；派遣、召回、闪避、问サチ四个小键；旋转镜头按钮或双指旋转；可以直接点世界里的东西来选中。所有按键不小于 48dp。
- **手柄**：左摇杆移动，右摇杆左右拨动旋转镜头，按住扳机打开性质环。
