# G3 灰盒原型：可玩试验场

**状态：技术预览（2026-10-14）。** 本页不是设计决定，只说明灰盒里有什么、怎么试、要验证什么。站点的摆放只为测试手感和系统，与已批准的地图 v2（map.md）无关；正式关卡在 G5 按地图 v2 做。所有名字、作物、小伙伴外形都是占位。

## 要验证的东西（对应 v0.1 的失败点）

| v0.1 的问题（knowledge/05） | 灰盒里的对策 | 怎么看出是否成功 |
|---|---|---|
| 要微调站位才能触发交互 | 目标选取：评分 + 75° 朝向锥 + 防抖；按键前就高亮并显示名牌；贴墙滑动 | 走近任何东西，不停脚也能稳稳选中；Tab 可换 |
| 反馈模糊 | 五步反馈：高亮 → 施法音 → 粒子流 → 落点音色（音高 = 她现在装了多少）+ 地面光环 → 东西本身变化 | 不看角落的数字也知道发生了什么 |
| 性质转移只剩"重" | 五性各有站点，且彼此连成因果 | 每种性质至少有一个"用了才有路"的地方 |
| 搬运是背包数字 | 原木、石块是实物；小伙伴走过去、凑够人手、扛着走过桥 | 资材堆上的木头是一根根堆起来的 |
| 交互物认不出 | 交互物轮廓、名牌上的性质珠（●○）、注连绳是唯一"动不了"的记号 | 截图里能指出每个能互动的东西 |
| 角色在阴影里闪 | 角色受保护光照（渲染地基） | 走进树荫，角色不闪 |

## 站点（以出生点为中心，北边是鸟居）

| 性质 | 站点 | 试试看 |
|---|---|---|
| 重 | 巨石、桥头的石压板、桥中间的门（绳子连着压板） | 从巨石取三份重（她变重、变慢，巨石失重浮起）→ 走到压板上把重给它 → 门开，而且一直开着（重量留在压板里） |
| 重 | 西边朽桥 | 身体重时踩上去会塌，她跌回岸边；身体轻（把重给出去）就能走过去 |
| 熱 | 火盆、西边溪水 | 从溪水取熱 → 结冰，可以走过去；从火盆取熱 → 她发橙光，碰到杂草会点着 |
| 光 | 鸟居旁的石灯笼（白天自己会攒光） | 取光 → 灯笼暗下去，她身上亮起来；夜里更明显 |
| 音 | 民家旁的鹿威し（会自己攒音）、鸟居西边的吊钟 | 从鹿威し取音，给吊钟 → 钟摆起来响 |
| 生 | 杂草、旁边的田 | E 种下胡瓜；从杂草取生，给田 → 一下长一截；收获 |
| — | 神棚（有注连绳） | 什么都取不走；E「归还」让身体回到本态 |
| — | 资材堆、工地（工地在鸟居东边） | F 派小伙伴把南岸的木头搬回资材堆；工地缺料时他们自己从资材堆搬过去；人在旁边才会动工；上梁有仪式 |
| — | 西北低地的鬼火 | 它太热、很饿，碰到会偷她的熱。取走多余的熱 → 平静，E 邀请加入；或者取走它的生 → 消散。两种结果都会被记下 |

身体容量：她偏离本态的总量有上限（现为 3）。取多了会被拒绝（"身体承受不住了"），需要给出去、放掉（L）或在神棚归还。

## 操作

- 桌面：WASD 移动 · `[` `]` 转镜头 · Z 缩放 · T 切时段 · 1–5 取 重熱光音生 · Shift+1–5 予 · L 再按 1–5 放 · E 情境 · F 派遣 · R 召回 · Tab 换目标 · Space 闪避 · H 收起说明。
- 手机：左半屏任意处按下出现摇杆；右下是情境键和五个性质键（点 = 取，上滑 = 予，下滑 = 放），外圈是派遣 / 闪避 / 召回，右上转镜头。

## 代码位置

- 纯逻辑（Node 可测）：`src/game/`（qualities、targeting、crew、build、farm、sim、nav）。
- 地形接入：`src/play/ground.js`；站点布局：`src/play/layout.js`。
- 表现：`src/play/views.js`（站点）、`src/play/actors.js`（她与小伙伴）、`src/play/art.js`（占位像素图）、`src/play/game.js`（主循环）。
- 渲染地基：`src/render/`、`src/world/`、`src/core/`（另见 knowledge/03）。
- 测试：`node --test tests/*.test.js`；`tests/field.test.js` 在真实地形上验证布局承诺（南岸只能经主桥到达、门挡得住、冰和朽桥成立）。
