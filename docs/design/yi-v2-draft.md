# 「移」v2：以效果为中心，没有数字（提案草案）

> 状态：**草案**（2026-10-14），进下一轮评审页。回应 G5R-2（用户原话见 decision-log）："这毕竟不是一个数值类游戏……更希望把游戏的玩法放在他的具体效果上面，就像旷野之息……王国之泪……参考这个机制思路……而不是完全地去硬套"。
>
> 不变的（已批准）：
> - systems.md 的三条定律：只搬运不创造、物不自变、A+B=AB；
> - 五性；取、予、放；
> - 她的身体就是货箱（R-6），菅笠之身（G5R-1）；
> - 注连绳是唯一的"不能取"标记。

## 0. 先说判断

- 0/1/2 三档、容量、性质珠，是我把《流れぬ雛》内部的账本原样搬到了玩家面前。用户问得准：一块磨盘和一座山岩，"三档"根本描述不了。数字也让玩家去算账，而不是去想"这东西有多重"。
- 塞尔达系列可以借的是哲学，不是数值。
  - 旷野之息的"化学引擎"只有几条一致的规则：元素改变材质的状态，元素改变元素，材质不改变材质。玩家用生活经验推测结果，组合起来效果成倍增长。
  - 王国之泪的能力，和智慧的再现的"回响"，都是一个动词作用在一个物件的物理属性上。屏幕上几乎没有数字。
  - 我们的「移」本来就是"动词作用在物件的性质上"，缺的是把"多少"交还给物件本身。

## 1. 新规则（玩家面对的只有这七条）

1. **性质的分量跟着东西走。** 每样东西天生带着它那种性质的分量：鹅卵石轻，磨盘重，山岩极重；烛火温，炭窑烫，温泉滚热；萤火微光，灯笼亮，正午的太阳刺眼。玩家看东西本身就知道，不需要读数。
2. **取，就是把那一份整个取走。** 磨盘失去重，就像空壳一样浮起来，被风推着走；烛火失去热，变成一团冷的、摇晃的光；风铃失去音，就哑了。失去性质的东西变"远"（遠化的规则：失去多少本来的性质，就有多远）。
3. **笠里只盛得下一件。** 她是一顶笠，翻过来能当篮子用，但一次只装一样。装进去的性质让她的身体变成那样东西的分量：
   - 取了鹅卵石的重，她只是走得稳一点；
   - 取了磨盘的重，她陷进土里，一步一顿，压得下机关，风推不动她，下水就沉；
   - 想取山岩的重，她会被压得趴在地上动不了，只能立刻松手。这本身就是反馈。
   要取别的，先把笠里这件交出去或放掉。
4. **予，是把笠里那一份整个交出去。** 接受的东西在本来的样子上多了这份性质。结果按"谁的分量给了谁"来想：
   - 磨盘的重给了一根树枝，树枝像磨盘一样砸下去，压断朽桥；
   - 炭窑的热给了一块冰，冰立刻变成一股白汽；
   - 萤火的光给了石灯笼，只亮起一点点；正午阳光给了它，亮得刺眼，夜里的小妖全被惊动。
5. **放，是让那一份散进四周。** 震地、火圈、闪光、咆哮、草木疯长，大小同样跟着来源的分量。散出去的回不来：来源会一直"远"着，直到有人把同类的性质还给它。
6. **交出她自己的。** 她自己是菅笠：轻、干、怕火、会沙沙响。她可以把自己那一点重交出去，就变得像被风掀起的笠，飘起来，借风过崖，浮在水上。过一会儿，笠会自己"想起"原来的分量，看得见、听得见地回来，所以拿自己做试验永远安全。
7. **遠化的东西，要还它同类的性质才回来。** 分量不对，结果也看得见：给遠化的背负子一根树枝的重，它只回来一点，还是轻飘飘的；给它一块山岩的重，它会把地压出一个坑。

环境是取之不尽的来源（已批准的第二条定律）：瀑布、太阳、炭窑、温泉。从环境里取，她装到的是"一笠"的分量，环境本身不会变远。

## 2. 屏幕上没有数字

- 没有份数、容量条、点数、性质珠。
- **她装着什么**：笠的颜色和纹样跟着变，笠沿挂着来源的小剪影（磨盘、烛火、风铃），脚步声、呼吸、走路姿态也跟着变。角落里只有一个笠形图标，显示装着哪种性质，不显示多少。
- **东西身上有什么**：被选中时，名牌上写名字和它带着的性质字（重・熱・光・音・生），不写多少。"多少"看东西本身：大小、材质、亮不亮、冒不冒烟、响不响。
- **失败也是效果**：
  - 取山岩，她被压趴、松手、喘气；
  - 对注连绳下的东西取，绳上的纸垂一抖，什么也没发生；
  - 笠里装着东西还想取，笠沿一晃、沙沙一响，提示已经满了。

## 3. 怪物和大东西（回答用户的问题）

- 不按数字设计，按"它是什么东西"设计。塗壁是一堵墙，墙有多重它就多重：
  - 取它的重，她像背了一堵墙，动不了；
  - 塗壁变得轻飘飘，风一吹就倒。
  这本身就是"平息"它的一种办法。
- 取活物的性质是一场拉扯：
  - 小妖会挣扎；
  - 她和它之间有一条看得见的性质流，被打中就断；
  - 取到一半它会逃，或者扑过来。
  所以不会一下子把敌人的「生」取光。杀与平息的细节和战斗提案一起写。
- 关卡和怪物设计改成"物件清单"：每种东西定义它是什么、带着哪些性质、每种分量属于哪个等级（玩家看不到等级，只看到东西）。

## 4. 新手教学的例子：梁与背负子（一次往返）

1. 祠的屋檐梁压着さぢ。她取梁的重：梁像空壳一样浮起来，さぢ爬出来。她自己变得和梁一样重，陷进土里，一步一顿。
2. 屋檐下那副遠化了的旧背负子（设定上，背负子是用祠的旧梁木做的，所以分量对得上）。她把这份重交给它：背负子"咚"地落地，颜色回来；她轻回原样。
3. 一次取、一次予，学会两个动词。不用像旧方案那样往返三次。

## 5. 防一招通吃（靠物理和代价，不靠数字）

- 一次只装一样。
- 每种都有代价：
  - 装着重就慢、下水就沉；
  - 装着热会烤到笠，菅草怕火，太烫了会自己烧起来；
  - 装着光招小妖；
  - 装着音没法潜行；
  - 装着生招虫和草食动物。
- 取走的东西会"远"，后果留在世界里：庄屋的柱子被取走了重，房子会歪；村里的人和小妖会注意到。

## 6. 关键变量、代价、什么时候选别的

- **好处**：玩家只想"这东西有多重、多烫"，用生活经验推测结果；大东西、小东西、怪物用同一套规则；不用教数字。
- **代价**：
  - 内部仍要给每种物件定一个分量等级，玩家看不到，关卡要逐件定义。
  - "分量太大"必须有清楚的表现，例如压趴、笠被烫焦。
  - 平衡要靠试玩来调。
- **选别的**：如果以后想要"同时装两样"的组合玩法，可以用剧情物件让笠多一个"格"，形状上看得见，仍然不显示数字。
