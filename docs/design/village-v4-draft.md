## 0. 纲要（一页）

### 0.1 一句话

**峠旁的隐里**：旧街道照旧翻过峠顶；她的家不在路上，在峠西侧一个浅浅的山坳里（约 45 × 40 米的"碗"），三面是坡和森林，开口朝西南，开口的边就是崖。从路上只看得见两棵老杉、一根道切り绳和后面的雾（P1）。

### 0.2 结构（从山下往上，也是序章第 1–6 场的动线）

### 0.3 和现在的地图比

- **留**：大楠（加磐座和根的接地、G 枝的碰撞）、茅屋（位置合理化、屋顶和檐下按 G5R3-36）、东门（两棵老杉 + 道切り绳，照旧从南往北进）、无缘墓（挪到石段顶的平台）、祠（变小，退到禁足地前）、眺望岩（做成崖口的花岗岩露头）、九十九折（重做，加节点和杉并木）、石段 16 厘米的级高、道路的路缘和踩出的中线、院子的生活痕迹、鸡猫乌鸦。
- **改**：整块平地 → 有坡、有岩、有崖的山坳；均匀撒开的小东西 → 成组、有主次、有留白；几团深红的叶子 → 只留一棵红叶，朱只给门槛；植物按光和水分区；路分真、行、草，材质过渡有收口。
- **北面的溪流**：建议不留在原位，改成"泉从磐座下涌出 → 流过苔庭东边 → 成为门内要过的那道水 → 在碗口跌成瀑布 → 流下山"。这一条要用户定（0.5 的第 2 项）。
- **去掉**：像贴图一样的大草和芦苇丛、把空间随意隔开的灌木、"被石头围起来的水泊"。

### 0.4 第二段怎么做

1. **比例表**：每样东西给米数，以及 P3 下的两种像素：世界物体（焦点处东西 30 像素/米、直立 21.2 像素/米，后倾份额 0 时）和精灵卡片（任何深度都按 30 像素/米画）。现在 57 像素的她在 P3 世界里相当于 2.69 米的直立物体，这是"像巨人"的一个主要原因（knowledge/29 §6–7）；身高方案要和渲染器那边 G5R3-42（P3 下的后倾、模型显扁）的调整一起定。
2. **美术资源总档** `docs/design/village/registry.json`：每个元素一条（编号、类别、种类、变体、用途、位置、朝向、尺寸、碰撞类型、能否交互、季节变体、设计说明、引用的原则）。编号按"类别-种类-序号"，例如 TR-CAM-01（大楠）、RK-IWA-01（磐座主石）、ST-SAN-03（参道第三段石阶）、WA-SPR-01（泉）、SG-MZG-01（瑞垣）。碰撞和画面从同一份数据生成。
3. **图纸**：一个 Python 脚本（`tools/design/`）读总档，出总平面图（SVG 和 PNG：分区、轴线与参道、路网与等级、等高线、水系、地标、视廊、可走与不可走的边界，每个元素标编号）和五张 P3 关键视角（家门口、结界入口、大楠下、眺望岩、九十九折，按 knowledge/29 §7 的视锥框出画面）。图面按造园图的规矩：图例、比例尺、指北针、线型分级、编号标签。
4. **设计说明**：每区的意图、对用户每条意见的回应、可走与不可走的视觉语言、提案。

### 0.5 要用户定的方向（第二段按提案格式写全）

1. **家的位置**：峠旁的山坳（推荐）／照旧在鞍部顶上／九十九折中段的一块台地。
2. **水**：泉在磐座下，溪是门内的门槛，碗口一道小瀑布（推荐）／保留现在北面的溪，只修源头和桥／不要溪，只留一口井。
3. **祠的分量**：树即神体，小祠 + 瑞垣围的禁足地（推荐）／正式的社殿和境内。
4. **她的身高**：两到三个方案（第二段给出米数、像素和对照图）。
5. **九十九折看得见几个弯**：六到九个弯，丁石刻到"九十九"，其余的弯在远景里（推荐）／更多的弯、更长的路。
6. **门后的路**：先往下到溪边、过水、再上石段（推荐，P2"下、渡、上"）／像现在一样，进门直接上石段。门照旧朝北进（现在就是从南往北进门，P3 下门在画面上方，保留）。
