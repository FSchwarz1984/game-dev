# 地图 v3（自然地形版）：提案草案

> 状态：**草案**（2026-10-14），和美术样章一起进下一轮评审页。
>
> 回应 G5R-4（原话见 decision-log）：
> - 要用新引擎的上限重做；
> - 不要"要么悬崖、要么阶梯"；
> - 近到远密密的好奇点；
> - 不用生硬提示，不用镜头指路；
> - 可以融合 3D。
>
> 小地图按 G5R-5（地图迷雾、传闻与手绘草图）。地点沿用已批准的 G5 范围（scope-g5.md 的七个地点）；改的是地形、密度和引导。

## 0. 判断

- 用户的批评对准两处：**高差语言**和**密度**。旧方案用"平台加崖"表达一切高差，这是 2D 斜投影画不了斜坡留下的技术妥协。换成"3D 场景按像素画渲染"后，连续的坡、山脊、沟谷都能画对，这个妥协就不需要了（是否走这条路线，由美术样章决定）。
- 事实更正：竖直的崖在地球上并不罕见，比如峡谷、海崖、断层崖、喀斯特；日本山村的石垣和梯田也本来就是人造的"台阶地形"。问题不在"有没有崖"，而在把崖和台阶当成唯一的高差语言，而且每半米一层。新地图里：
  - 崖只出现在峡谷和瀑布；
  - 石阶、石垣、梯田只出现在人会修的地方：寺的参道、小屋的院子、田；
  - 其余全是连续的地形。

## 1. 地形（G5 范围）

一座山口：南北两个坡夹着一条鞍部。

- **南坡**：旧街道从平原上来，在坡上折返几十次，所以叫九十九折。坡上有杂木、芒草、几块露出地面的大岩；眺望岩是一块伸出去的岩嘴，脚下就是遠化的平原。
- **鞍部（家）**：大楠在鞍部最高处，树冠罩着小屋、祠和无缘墓，泉水在北侧的浅沟里冒出来。
- **北坡**：缓缓降进杉林盆地。废寺的参道是一段石阶，寺后是隧道北口和信号所。
- **东侧**：竹子覆盖的山脊。炭窑在半坡，烟从竹梢上冒出来；山脊另一边是温泉沟（G5 只到沟口）。
- **坡下**：几层梯田和溜池，水闸控制着往下的水。
- **西侧**：峡谷，有吊桥，还有瀑布的水雾。全图唯一成片的崖在这里。
- **边界**：峡谷、山顶的陡崖、遠化之雾。雾看得见，剧情里先解释过，往里走路会越走越长，最后把她送回来。不用空气墙。

高差的走法：
- 坡在 35° 以内都能走；更陡的地方要绕，或者用性质：失重时借风从坡上飘下去，变重时顺着碎石坡滑下去。
- 人修的捷径：石阶、梯田的田埂。

## 2. 好奇点：近、中、远三层

| 距离 | 在她附近多久就能遇到 | 例子 |
|---|---|---|
| 近 | 每一屏 | 一根断枝（可以搬）、柿子树上的果、一只鬼火、能砍倒的枯树、发着光的供品箱、挂着风铃的屋檐、地藏和供品、蘑菇、一只草鞋、一只狐狸、几只乌鸦 |
| 中 | 跑 10–30 秒 | 樵夫留下的营地、塌了一半的小屋、炭窑的烟、半埋在杉林里的鸟居、横在溪上的倒树（能走）、钻进阴影里的石阶、寺钟的声音 |
| 远 | 鞍部和眺望岩上看得见 | 山顶「隔」铁塔（夜里亮红灯）、瀑布的水雾、废寺的屋顶、平原上遠化的白、铁道高架桥 |

- 每一样好奇点都给「移」带来回报：一种值得取的性质、种田或施工用得着的东西、一个可以唤醒的旧器物、一条新的路。
- 鞍部是"走出洞口"的那一刻：她第一次走到眺望岩，四个方向各有一个远处的好奇点，东边的烟、北边的屋顶、西边的水雾、南边的平原。这是地形和视线造出来的，不靠镜头。

## 3. 引导：不用镜头，不用生硬提示

- **视线**：地形开口对着地标；树、山脊、屋顶按三角形法则遮挡与揭示，翻过一道坡，才露出下一个。
- **声音**：钟、瀑布、风铃、遠囃子，每个声音都有看得见的声源。
- **光**：夜里的灯笼、鬼火、铁塔红灯。
- **人的痕迹**：被踩出来的小路、路边的地藏、樵夫留下的绳子，自然地把人往有东西的地方带。
- **さぢ**：
  - 铃在好奇点附近轻响，这是世界里的声音，不是界面；
  - 她会对看得见的东西说话（"那边冒烟了！"），但只在玩家已经能看见的时候说。
- **不做**：
  - 画面中间的说明、箭头、目标标记；
  - 镜头自己转过去告诉你去哪。
  第一次的操作提示只在玩家走近之后出现，挂在物体上。

## 4. 小地图（G5R-5）

- **地图迷雾**：她走过的地方按视野半径揭开，画成墨线：地形、路、她见过的东西。
- **传闻与草图**：
  - 城镇建设引来的人和小妖会讲传闻，或者留下一张手绘草图；
  - 草图在小地图上是一层淡墨，只有粗略的地貌，有时是错的：比如樵夫记得的路已经被遠化冲没了；
  - 亲自走到那里，淡墨换成真正的墨线。
- 玩家可以自己在地图上盖印。地图上没有目标标记。
- 这条线也经过「移」：城镇建设本身就是搬运，房子盖起来，人才会来，传闻才会来。

## 5. 无缝

一张地图，按区域流式加载，没有加载画面，没有分段卡。

## 6. 依赖与代价

- 依赖美术样章：自然地形的画法、3D 像素渲染路线要先过你这一关。
- 代价：
  - 自然地形的寻路、碰撞、遮挡比平台加崖复杂；
  - 好奇点的密度意味着大量物件，要做生成工具；
  - 手机性能要早测。
- 选别的：如果样章没有通过，回到 2D 的话，自然高差只能靠缓坡的明暗和人造台阶来画，"站在高处往外看"的感觉会弱很多。
