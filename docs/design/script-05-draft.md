## 0. 这一版和第四版差在哪

第四版的骨架用户认可了，这一版不动骨架，动的是"声音"。knowledge/27 找到的四个"不够出彩"的原因，和这一版的改法：

| 第四版的问题 | 第五版 |
|---|---|
| 三个人的差别停在用词上：句子长短、语气词、敬称的分布差不多 | 每个人一张分布表（第 1 节）。小鹊对人几乎不用语气词，**只对身旁的空位用**；さぢ语气词最多；婆婆话轮长、句子短、信息少 |
| 小鹊的笑点只有一种形状："对方一问，她短短一答，句号收"，约八句 | 只留四处（"没吃。／背上了。"等）。其余换成：运货人的套话（"这单我接了""点清了""我先替您收着"）、说起本行停不住的长句（被人截断）、用郑重的说法讲小事（"落地的时候，略有差池。"） |
| 症状一处也没"漏出来"：没有口误，没有差点说出口的词，没有"玩笑加撤回" | 三处：①第 6 场数灯数到九十九，差一点说出"一百"；②第 0 场婆婆硬塞鼓槌，她脱口"不要——"，自己咬住，换回套话；③婆婆开小鹊不老的玩笑，再说"说笑的" |
| 婆婆没有只属于她的习惯 | 她有一个只有她叫的小名"鹊儿"（日文「かさっこ」）；开口第一句带出她一辈子的心事："……这下齐了。"；话轮更长，多出来的是闲话、吃的、身体 |
| 收到礼物的那一刻没有写成症状 | 礼物在她手里一律变成寄存或货款：鼓槌"我先替您收着"，救さぢ是"一单"，婆婆多捏的饭团拿去"抵房租" |
| 收音机只是"大他者的声音" | 公共广播的敬体，对着空山说"各位"，信号断续；断出来的词里有"名字"（她丢的正是名字） |

## 1. 声音的分布

### 1.1 每个人一张表

| | 小鹊 | 婆婆 | さぢ |
|---|---|---|---|
| 日文的敬语 | 对谁都用です・ます，对石像、乌鸦、收音机也一样；干活时用谦让的套话 | 常体，轻的东北色（「おら」「〜べ」「〜でねえ」「〜っから」） | 平时常体加小孩的句尾（「〜もん」「〜の」「〜でしょ」）；怕极了，切到庄屋待客的老派敬语；一放心就掉回来 |
| 日文的终助词 | 对人几乎为零；「ね」只给空位 | 「な」「よ」「べ」 | 「ね」「よ」「もん」「の」最多：她一直在跟人确认，沉默就是被丢下 |
| 中文的语气词 | **只对空位用**（"是吧""呢""吧"）；对人、对物不用 | 有，不多（"啊""吧"） | 多（"啊""呀""嘛""呢"） |
| 自称 | 「わたし」／"我"。"我的"全剧只说一次（"这是我的背负子。"） | 「おら」／"我" | 「うち」（既是"我"，又是"家"；要你定，第 7 节）／平时"我"，宣布所有权、害怕时"人家" |
| 叫对方 | "您"。全剧只掉一次：第 0 场"不要——" | 小名「かさっこ」／"鹊儿"，一场叫三次 | "你"；怕的时候"这位客人""您" |
| 说不出口的词 | 「帰る」（回家）只说「戻る」；"一百"；收礼时的「いただきます」（"收下了"） | 请求本身（"你来敲鼓"） | 那户人家的姓 |
| 句子的节奏 | 三种轮换：固定的套话；说起路、分量、时辰停不住的长句（常被截断）；躲闪的短句 | 话轮长，句子短，靠「んだ」「ほれ」「だから」一路接下去；请求说一半停 | 一口气用「て」串下去，拟态词多（「びよーん」「ずーっと」「じんじん」） |
| 失手 | 第 0 场脱口"不要——"；第 6 场"一——" | 说到老伴的鼓槌，话变短，只剩"顺路" | 说出「うち」自己愣住；说到"我们家"就停 |

### 1.2 小鹊的套话（全剧一字不差）

| 日文 | 中文（固定译法） | 出现在 |
|---|---|---|
| 承りました | 这单我接了。 | 第 10 场 |
| お預かりします | 我先替您收着。 | 第 0 场 |
| 確かに | 点清了。 | 第 2 场 |
| 〜でお支払い済みです | 那是付过桃的。／它付过团子了。 | 第 3、7、12 场 |
| お代に | 拿这个抵（房租）。 | 第 11 场 |

"お預かりします"是她最要紧的一句。别人送她东西，她不说「いただきます」（我收下了），说「お預かりします」（我先替您收着）：礼物在她手里变成寄存品。礼物会把来往合上：没有东西要运，没有账要结，她就没有位置；寄存让来往重新开着（knowledge/27 §2.1、§5.2.1）。全剧里她还没有一次真的"收下"。

### 1.3 不会说话的搭档

- 乌鸦：日文「カア」，中文"嘎"。叫在她夸口、否认之后那一拍上。一场一两声。
- 收音机：噪音日文「ザ」，中文"沙"；说话用公共广播的敬体，对着"各位"。
- 空位：不回答。停顿就是它的回答；她偶尔替它点头。

## 2. 序章「送り盆」

### 第 0 场　庄屋后门

**事实表**：同第四版。改动：
- 婆婆管小鹊叫"鹊儿"（「かさっこ」），只有她这么叫。
- 婆婆硬塞鼓槌时，小鹊脱口一句"不要——"，自己咬住，换回套话；出门前把鼓槌说成"替您收着"。她没答应敲鼓，也没把鼓槌还回去。

## 7. 要你定的

1. **さぢ的自称。**
   - 推荐：日文用「うち」（既是"我"，又是"家"），中文平时说"我"，宣布所有权和害怕的时候说"人家"。"人家"在中文里也有两层：小孩撒娇时的"我"，和"别人"。"这是人家的家！"读起来是"这是我的家"，也是"这是别人的家"——座敷童子住的，从来都是别人的家。
   - 代价：「うち」带一点西日本小女孩的色彩，而座敷童子的民俗在东北；中文"人家"用多了会嗲，所以只用三次。
   - 选别的：日文用「わたし」，中文只用"我"，第 11 场改回"这是我家！"，第 12 场的"人家就是我！"删掉。
2. **婆婆的方言和村子的地域。** 日文稿给了很轻的东北色（「おら」「〜べ」「〜でねえ」「山さ」），因为座敷童子、远野、盂兰盆的这一套民俗在东北。中文稿不带地域色（knowledge/26 的结论）。地图和世界观至今没写村子在哪里。要不要定在东北，以后单独提案；在那之前日文稿保持这么轻。
3. **婆婆的玩笑"该不是让山神看上了吧"。** 推荐留。她是"百関"之神，不是山神：玩笑说中了一半，错了一半。如果你觉得太近，换成"该不是喝了山里什么泉水吧"。
4. **"九十九、一——"。** 推荐留。全剧只有这一次，就在天裂开的那一秒。
