# G5 新手区垂直切片的范围（草案）

> 状态：**草案，待审批**（2026-10-14）。G5 = 新手区的第一段完整体验，用来验证"这个游戏好不好玩"。完整的新手区（全部十七个地点）在 G5 通过之后再铺开。

## 坦白：范围已经很大

用户在 G0 之后加入了：三人都在新手村登场、小伙伴收集与可视搬运、城镇建设、更多作物、杀或平息、更复杂的地图。每一项单独都是一个大系统。旷野之息的初始台地本身就要 2–4 小时；我们的完整新手区按这个规模估计也是数小时的内容。

所以 G5 只做**每个系统的一颗种子**，并且每颗种子都必须通过「移」连起来。如果某个系统在 G5 里还接不上「移」，它就推迟。

## G5 包含

| 方面 | 内容 |
|---|---|
| 时长 | 约 45 分钟（原定 30–45 分钟，范围扩大后取上限） |
| 地点 | 家（大楠）、九十九折宿、梯田与溜池、竹林与炭窑、废寺、吊桥与峡谷、隧道北段（虚线框内） |
| 角色 | ツヅラ（全程）、サチ（第一天早上起，派蒙位）、シオン（中段加入） |
| 「移」 | 五性全部可用，每种至少走完四拍教学中的前三拍 |
| 小伙伴 | 6 种付丧神（籠、草鞋、鉄瓶、提灯、鍬、鋸）+ 2 种可平息的小妖（鬼火、塗壁）；跟随、派遣、召回、可视搬运 |
| 建设 | 资材堆、设计图、七阶段施工；3 种房间配方（囲炉裏の間、寝間、神棚の間）；第一栋宿屋的上梁仪式 |
| 种田 | 一块家门前的田 + 一层梯田；4 种作物（胡瓜、茄子、鬼灯、蕎麦） |
| 小妖 | 4 种（鬼火、黒坊主、塗壁、山彦），杀或平息都可以，后果被记录并在台词中体现 |
| 演出 | 序章、サチ登场、シオン登场、上梁仪式、结尾（难民的灯） |
| 平台 | 桌面与手机都能完整通关 |

## G5 不包含

完整的十七个地点、全部作物与小伙伴、第一章的难民、凭依与化身、长期结局分支。
