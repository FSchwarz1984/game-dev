# 操作 v2：指哪打哪（提案草案）

> 状态：**草案**（2026-10-14），进下一轮评审页。回应 G5R-3：两种旧方案"都没有解决……画面中出现多个可交互的物品、敌人……我不能说我想指哪打哪……哪怕说，像手机端 moba 那样有可滑动的操作指针……我还是希望你能拿出一个更好的解决方案"。
>
> 前提：「移」v2（`yi-v2-draft.md`）。笠里一次只装一样，所以"取"要选性质，"予"和"放"不用选：手里只有一件。

## 0. 判断

- 旧方案的病根是**先选动作、再让系统猜目标**。目标一多，系统就猜错。正确的顺序是**先指目标、再下动作**，而且三种输入都要有真正的"指"：鼠标指针、手柄右摇杆的准星、触屏拖动的准星或直接点物体。
- 再加一层：**只亮能用的目标。** 按住"取熱"时，画面上只有带熱的东西亮起，其他的暗下去。指向的难度一下子降下来，"指哪打哪"才不会变成"像素级瞄准"。
- 自动选取保留，降为辅助：手指快速一点、手柄不动右摇杆时，用旧的打分规则（距离、朝向夹角、类型优先）选出当前最合适的那个，并且一直在世界里描边，让玩家看见"现在会打到谁"。

## 1. 方案

| 方案 | 内容 | 代价 |
|---|---|---|
| **A 先指后做（推荐）** | 三种输入都有精确的指；动作只有四个：取（选性质）、予、放、交出自己的；按下动作时只亮能用的目标；松手才生效，拖回去就取消 | 要做三套"指"的手感，触屏的拖动准星要反复调手感 |
| B 锁定切换 | 像塞尔达的 Z 注目：一个键锁定最近的目标，再按切换下一个，动作作用在锁定目标上 | 目标多时要按很多下才轮到想要的那个，做不到"指哪打哪" |
| C 全平台拖动瞄准 | 电脑也用"按住动作键拖鼠标"瞄准 | 电脑上反而比直接指慢；鼠标本来就是最好的指针 |

## 2. 方案 A 的细节

### 电脑（键鼠）
- WASD 移动，**鼠标就是准星**：指针下方（以及周围约一个角色宽度内最近的）可交互物描边，名牌挂在它身上。
- **1–5**：从指着的东西取那种性质。
- **左键**：予，把笠里那件交给指着的东西。笠里空着时，左键是普通互动（说话、拿起、开门）。
- **右键**：放，往指针方向散出去，短距离。
- **按住 1–5 约 0.35 秒**：交出她自己的那种性质。按下 0.1 秒内先有声音。

### 手柄
- 左摇杆移动。**右摇杆一动就出现准星**，沿摇杆方向吸附到最近的可交互物；轻拨一下就切到同方向的下一个。
- 按住 LT 出现性质环：只有准星目标身上有的性质是亮的。用面键选一种，松开 LT 就取走。
- RT 是予，RB 是放，A 是互动，B 是闪避。
- 右摇杆不动时，准星落在自动选出的目标上。

### 触屏（只横屏）
- 左半屏是浮动摇杆。
- 右下有五个性质键，排成弧形，中间是笠键（显示笠里装着什么）。
- **拖动瞄准（类似手机 MOBA，但吸附在物体上）**：
  - 按住性质键往外拖，世界里出现准星，方向和距离跟着手指，最远到她够得着的地方，并吸附到最近的、**带这种性质**的东西上。
  - 她和目标之间预演一条性质流的虚线。松手就取。拖回键上就取消。
- **快点**：轻点性质键，作用在当前自动选出、已经描边的目标上。
- **笠键**：
  - 拖动瞄准是予，轻点是予给描边目标；
  - 长按是放（散在身边），往外拖远再松手是往那个方向放。
- **直接点物体**：点世界里的东西，它就成为当前目标，一直保持到她走远。之后再点性质键，就作用在它身上。

### 三种输入共同的反馈（法术五步，已批准）
预览（目标描边、名牌、性质流虚线）→ 施放（她的手势，0.1 秒内必有声音）→ 可见状态 → 可预测的结果 → 回报。指向无效时（没有这种性质、太远、注连绳）也给反馈：准星变灰、名牌上写原因、一声轻响。

## 3. 关键变量、选别的

- **关键变量**：多目标时能否一次指中；三种输入能否用同一套心智模型（先指后做）；触屏不靠精细点按。
- **选 B**：如果你更看重手柄上的极简（只有锁定键），并接受目标多时多按几下。
- **选 C**：如果你希望电脑和手机的操作手感完全一样。
