# 作品名（草案）

> 状态：**两轮被否决**（2026-10-14）。第一轮《ツヅラ —遠囃子—》"太土气太普通"；第二轮『モノノアワイ』"不够吸引眼球，没有让人想打开的冲动"。重新提案中。

## 推荐：『モノノアワイ』

- 读法 Mono no Awai。"物の間"：物与物之间。
- 对日本观众是一眼认得出的变奏：把古典美学词"物の哀れ（もののあわれ）"改了一个音，变成"物の間（もののあわい）"。
- 三层意思都落在作品上：
  - **物（もの）**：付丧神是"物"成了精，小伙伴全是器物；"物の怪（もののけ）"也是同一个"もの"。
  - **間（あわい）**：此岸与彼岸之间、近与远之间、篱笆内外之间——先达走的就是这个"之间"。
  - **移**：性质从一物移到另一物，发生在"物与物之间"。
- 撞名检查：没找到同名游戏（2026-10-14）。但《モノノケの国》（スタジオライツ，和风妖怪动作 RPG，2026 年秋 PC）与它开头同为"モノノ"，有一定混淆风险。
- 英文标题可以直接用 MONO NO AWAI，或加副题。

## 备选

- **『アワイノシルベ』**（間の標，"之间的路标"）：更长，更诗意，暗示先达的隐藏身份（シルベ = 引路的标记）。没有找到撞名。
- **『百鬼帳』**（ヒャッキチョウ，"百鬼的名册"）：最直接地传达收集玩法，好记；但"百鬼"在中日手游里用得很多，辨识度会被稀释。

## 已排除

- 『九十九夜行』：已有同名的单篇漫画（2021），英文"Ninety-Nine Nights"是 2006 年的游戏。
- 『ウツシヨ』：已有《うつしよの帳》（2016，已停运）。
