# 世界与故事（G1 草案）

> 状态：**宇宙观被否决**（2026-10-14，G1-6：要更复杂、更宏大、原创，像异度系列；民俗只作润色），重新提案中。登场节拍已通过。

## 宇宙观（只给开发者看；玩家要很久以后才拼出来）

- **百鬼夜行**：每逢某些年的送り盆（八月十六日，送魂之夜），一支夜行队伍从这个世界走向彼岸，带走"已经用尽的东西"：用了九十九年的器物、该走的魂、到期的约定。队伍敲着祭囃子。凡人只在极远处听见过，所以叫**遠囃子**。
- **先达**：走在队伍最前面引路的人。她量着此岸与彼岸之间的距离，让近的保持近、远的保持远。距离本身是被她"走"出来的。
- **三十年前**：铁道隧道贯穿了这座山（军方的「隔」计划？存疑），旧街道被废弃，那一年的夜行在山口出了事。先达失去了记忆，在峠上醒来，以为自己只是一顶笠成的精。这就是ツヅラ。
- **今年的送り盆**：夜行又来了，却没有先达。队伍迷了路，没有只带走"用尽的东西"，而是扫过整片土地，把沿途万物的性质——重量、温度、光、声音、生气——一起带向了彼岸。这就是**遠化**：东西还在原地，却不再"近"。
- **遠囃子还在响**：迷路的夜行仍在附近绕圈，敲着祭囃子，寻找它的先达。
- **九十九与一百**：ツヅラ只数到九十九；百鬼帳（小伙伴图鉴）有九十九格加一格空白；她的姓是"百々"。第一百个，是她自己。

## 序章：送り盆（约 8–10 分钟）

保留 v0.1 被认可的电影式演出（镜头、停顿、字幕卡、树顶远景）。

1. 黄昏的九十九折峠。ツヅラ背着货爬山，替山下的庄屋给峠上的无缘墓送供品（顺手扣下一颗柿子）。
2. 遠囃子从四面八方响起。她说"今天十六号，送魂的晚上"。
3. 她爬上大楠：山下平原的灯火；一列灯笼从平原上升起，走进夜空（百鬼夜行）。
4. 一圈苍白的"远"从灯列脚下扩散，扫过平原、扑上山口。她对着平原喊："喂——那边的人——"
5. 白场。

## 新手区：九十九折峠的几天（盂兰盆之后，夏末）

主线只有一条很细的线，其余全靠好奇心（初始台地原则）：

1. **第一天早晨**：她的歩荷小屋"远"了：看得见，摸不到。大楠也褪了色。サチ从山下逃上来，宣布"你背上这个就是我家"。
2. **学会「移」**：被压在倒下的梁下（取走梁的重量）；教学在情境里完成，サチ吐槽、铃声提示。五性各按四拍教学，分散在新手区各处，不按顺序强制。
3. **第一个付丧神**：在废宿场里找到一只老籠，ツヅラ把一点"魂"给它——它站起来了。百鬼队（小伙伴系统）开始。
4. **九十九折宿**：被遗弃三十年的宿场成为据点。先修自己的小屋，再修宿屋。施工全程可见：小伙伴扛木头、垒础石、立柱、铺茅草。
5. **废寺与シオン**：她扛着ツヅラ家的柱子（误会）。她一眼认出了ツヅラ，却什么都不说。加入后成为最强的搬运和木工。
6. **小妖**：遠化饿坏了的小妖开始偷吃性质。杀还是平息，由玩家决定（见 `systems.md`）。
7. **上梁仪式**：第一栋宿屋建成，三人和小伙伴们抛年糕。这是新手区的情感高点。
8. **结尾**：夜里，山路尽头的远化之雾里亮起一列灯——不是夜行，是人：第一批难民。第一章开始。

## 贯穿的谜线（新手区只露头，不解答）

- 遠囃子从哪里来？（玩家会在隧道深处和山顶听到它更近。）
- 山顶生锈的「隔」字铁塔：军方在三十年前做了什么？
- シオン为什么一眼就认出ツヅラ，却什么都不说？
- サチ的好运为什么唯独对ツヅラ不灵？
- 百鬼帳第一百格为什么是空白？
- ツヅラ为什么数到九十九就停？

规则（来自 v0.1 的教训）：**谜只能在意义上，不能在感知上。** 每一个谜都必须让玩家清清楚楚地看见、听见，只是不知道为什么。
