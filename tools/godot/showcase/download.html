美术样章 Windows 版

给你亲自验证画面用的版本：家一带、眺望岩、序章的树顶远景、立绘和对话演出。可以走动，调时刻和天气；没有剧情。这一版不放人物：小鹊的模型在重做，家一带和眺望岩里是看不见的走路点带着镜头走。

下载

Tengan_ArtSample.zip

文件分成几块放在这个页面里，点按钮后页面把它们取回、逐块核对 SHA-256、拼回一个 zip，再请你确认保存。

运行

  1. 把 zip 里的整个文件夹解压出来。tengan.exe 和 tengan.pck 必须在同一个文件夹里。
  2. 双击 tengan.exe。程序没有数字签名，Windows 可能提示"Windows 已保护你的电脑"：点"更多信息"，再点"仍要运行"。
  3. 默认全屏。F11 或 Alt+Enter 在全屏和窗口之间切换。

需要 64 位的 Windows 10 或 11，显卡支持 Vulkan（不支持时自动改用 Direct3D 12）。

眺望岩：走上岩石，站定一会儿，镜头会望向远方；A / D 转向，W / S 回来。树顶远景放完后按 Enter 重放。立绘：↑↓ 换表情，←→ 换人物，空格重放对话演出。zip 里的 README.txt 有同样的说明。
