天岸　美术样章（2026-10）

这是美术样章，不是游戏的正式一段：可以在家一带走动、调时刻和天气，看眺望岩、序章的树顶远景、立绘和对话演出。没有剧情。
这一版不放人物：小鹊的 3D 模型正在重做，家一带和眺望岩里是一个看不见的走路点带着镜头走。

【运行】
- 把整个文件夹解压出来，双击 tengan.exe。tengan.pck 必须和它在同一个文件夹里。
- 第一次运行时，Windows 可能提示"Windows 已保护你的电脑"：这是因为程序没有数字签名。点"更多信息"，再点"仍要运行"。
- 默认全屏。F11 或 Alt+Enter 在全屏和窗口之间切换。
- 需要 64 位的 Windows 10 或 11，显卡支持 Vulkan 或 Direct3D 12。

【操作】
菜单：↑↓ 选择，Enter 确定（手柄：十字键、A）。

家一带、眺望岩：
  WASD 或方向键　移动（手柄：左摇杆）
  按住 Q / E　　 时刻往回 / 往后（手柄：LB / RB）
  1 2 3 4　　　　清晨、正午、黄昏、夜
  T　　　　　　　让时间自己走（一小时约 30 秒）
  R　　　　　　　下雨 / 停雨（手柄：Y）
  H　　　　　　　隐藏 / 显示按键提示
  Esc　　　　　　回菜单（手柄：B 或 Start）
眺望岩：走上岩石，站定一会儿，镜头会望向远方；A / D 转向，W / S 回来。

序章·树顶远景：自动播放，放完后按 Enter 重放。
立绘：↑↓ 换表情，←→ 换人物，空格 重放对话演出。
